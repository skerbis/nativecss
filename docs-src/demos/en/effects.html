Purely decorative, optional components (layer "components", components/effects.css) - animated gradient border, pulsing glow and glassmorphism. Meant to be combined with other components, not part of .ncss-card/.ncss-btn.

Glow Border

Rotating conic-gradient() ring on a ::before - no wrapper element needed, works on any element with its own background. The angle runs through a custom property typed via @property (--ncss-glow-angle) so the browser can interpolate it cleanly.

Card with border

The same class also works on a regular .ncss-card-like surface, not just on buttons.

Border + pulse combined

.ncss-glow-border and .ncss-glow-pulse use different animation properties (background vs. box-shadow) - freely combinable.

<button class="ncss-glow-border">Ask AI</button>

<!-- customize via custom property, per instance -->
<button class="ncss-glow-border" style="--ncss-glow-speed: 1.5s;">Faster</button>

Tokens: --ncss-glow-colors (default: brand/secondary/success color), --ncss-glow-speed (default 4s), --ncss-glow-thickness (default 2px), --ncss-glow-radius (default --ncss-radius-lg).

Glow Pulse

Pulsing box-shadow - usable on its own, e.g. to highlight a single call to action.

Live 
<button class="ncss-btn ncss-btn--primary ncss-glow-pulse">Get started</button>

Glass (Glassmorphism)

Semi-transparent surface + backdrop-filter: blur() saturate() - guarded with @supports; without support you get a plain semi-transparent surface without blur.

Card 1

Only shows its effect in front of a colorful/busy background - see the gradients behind these cards.

Card 2

Combinable with .ncss-glow-border for an extra border accent.

Card 3

Glass + glow border together.

<div class="ncss-glass">...</div>

<!-- adjust blur/color -->
<div class="ncss-glass" style="--ncss-glass-blur: 20px;">...</div>

Tokens: --ncss-glass-bg, --ncss-glass-border, --ncss-glass-blur (default 12px).

Backdrop (background image slideshow)

Images slowly crossfade while gently zooming out - typically used as a page-wide, fixed background behind glass surfaces (components/backdrop.css + js/backdrop.js). Shown here as the embedded variant .ncss-backdrop--contained; with prefers-reduced-motion it stays on the first image, without zoom.

Content over the image

Glass surfaces stay readable while the image sets the mood. Changes every 4 seconds, pauses in background tabs.

<!-- page-wide, directly in <body> -->
<div class="ncss-backdrop" data-ncss-backdrop data-interval="6000" aria-hidden="true">
  <img class="ncss-backdrop-item" src="a.jpg" alt="" fetchpriority="high">
  <img class="ncss-backdrop-item" src="b.jpg" alt="" loading="lazy">
</div>
<script src="dist/js/backdrop.js" defer></script>

<!-- fill a single section only: ancestor with position:relative -->
<div class="ncss-backdrop ncss-backdrop--contained" data-ncss-backdrop>...</div>

Tokens: --ncss-backdrop-fade (crossfade, default 1.6s), --ncss-backdrop-zoom (start scale, default 1.08, 1 = no zoom), --ncss-backdrop-tint (overlay tint, e.g. light-dark(transparent, rgb(0 0 0 / 50%)) for calmer surfaces in dark mode).

Stamped (engraved border)

Just a hairline two-tone border (dark top-left to light bottom-right, like an edge engraved into the material) - no background color of its own, so it works on plain white too. .ncss-stamped alone lifts on hover ("comes forward"); adding .ncss-stamped--press reverses this and sinks deeper on hover. In both cases :active (click/touch held) sinks in even further.

<button class="ncss-stamped">Lifts on hover</button>
<button class="ncss-stamped ncss-stamped--press">Sinks on hover</button>

Tokens: --ncss-stamped-thickness (default 1px, ring thickness), --ncss-stamped-dark/--ncss-stamped-light (default rgb(0 0 0 / 35%)/rgb(255 255 255 / 90%)), --ncss-stamped-lift (default 3px, travel on hover/active), --ncss-stamped-radius (default --ncss-radius-lg).

Combined with .ncss-btn variants: the ring is semi-transparent black/white (rgb(0 0 0 / 35%)/rgb(255 255 255 / 90%)) instead of a fixed color - it automatically blends with each button's background color when painted (alpha compositing), WITHOUT .ncss-stamped itself needing to know anything about brand color/variant. Only the corner shape is NOT picked up automatically by .ncss-stamped (its own default is --ncss-radius-lg, larger than .ncss-btn's --ncss-radius-sm) - so set --ncss-stamped-radius explicitly to the matching value:

<button class="ncss-btn ncss-btn--primary ncss-stamped"
        style="--ncss-stamped-radius: var(--ncss-radius-sm);">
  Primary + Stamped
</button>

Grain (grain/sand texture)

Fine noise via an SVG <feTurbulence> filter as a data URI - no image asset, no build step. Subtle by default and adjustable via --ncss-grain-opacity; for a "sandy" look, adjust blend mode/opacity. The default blend mode overlay behaves like multiply on dark surfaces and like screen on light ones - so on a VERY dark/saturated surface (e.g. .ncss-surface--brand-2) the default opacity is practically invisible, while on a mid-tone surface (left) the same default shows clearly. For dark/saturated brand surfaces, either raise the opacity considerably or switch to --ncss-grain-blend: soft-light (right).

Subtle (default)

--ncss-grain-opacity: 0.12 (default) on a mid-tone surface

Sandy

--ncss-grain-opacity: 0.4, --ncss-grain-blend: soft-light

<div class="ncss-grain">...</div>

<!-- stronger/different tint, for dark/saturated surfaces -->
<div class="ncss-grain" style="--ncss-grain-opacity: 0.4; --ncss-grain-blend: soft-light;">...</div>

Tokens: --ncss-grain-opacity (default 0.12), --ncss-grain-blend (default overlay).

Blend modes

.ncss-blend-* (helpers/elevation.css) are 1:1 utilities for mix-blend-mode - the element blends with whatever lies BEHIND it (a different case from --ncss-grain-blend above, which is background-blend-mode and only blends between an element's own background layers). Forced color scheme per element

Not to be confused with the page-wide theme override via [data-theme] (colors.css, e.g. a toggle in the UI) - same principle (color-scheme), just applied locally to a single element instead of :root. color-scheme is inherited - .ncss-scheme-dark/.ncss-scheme-light (helpers/surfaces.css) force a color scheme ONLY for an element and its descendants, regardless of the theme of the rest of the page. All light-dark() tokens in the content flip automatically, without duplicating any values.

Always dark

.ncss-scheme-dark, regardless of the page theme.

Always light

.ncss-scheme-light, regardless of the page theme.

<div class="ncss-scheme-dark">...</div>

Motion respects prefers-reduced-motion automatically (globally in reset.css, not retrofitted per component) - with the setting enabled, only a single frame runs.
