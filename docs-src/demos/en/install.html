1Copy

Recommended: unzip the release ZIP from GitHub (nativecss-<version>.zip, only dist/ + licence, about 430 KB, from v1.1.0). Alternatively git clone https://github.com/skerbis/nativecss.git and use its dist/.

Copy dist/ into your project (e.g. as ncss/) and link it - done.

<link rel="stylesheet" href="ncss/ncss.css">
<link rel="stylesheet" href="ncss/theme.css">

2CDN

Load straight from jsDelivr, no download.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@skerbis/nativecss@1/dist/ncss.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@skerbis/nativecss@1/dist/theme.css">

In production pin a version, e.g. @skerbis/nativecss@1.1.0.

3npm (optional)

For projects that already use a bundler.

npm i @skerbis/nativecss

import "@skerbis/nativecss";              // JS entry
@import "@skerbis/nativecss/dist/ncss.css";    /* or in CSS */

4With a CMS

REDAXO 6 + fluid: the fluid add-on ships a ready NativeCSS kit (Website → Kit → NativeCSS) - with blocks, design settings and front-end editing.

KLXM Studio: NativeCSS kit for KLXM Studio - coming soon.

npm is just an extra option - NativeCSS needs no build step. Copy, CDN and npm deliver the same files - fluid and KLXM Studio already ship them.
