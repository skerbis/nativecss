Data-driven widgets (JSON or .ics) as a native HTML alternative to iframe embeds - searchable, themeable via CSS, no cross-origin/height issues. Everything is opt-in: js/ics.js, js/events.js, js/downloads.js - include each only on pages that actually use it.

Calendar (month grid)

data-view="month" - events as dots on the day, clicking opens the day as a .ncss-modal. Source here: data/events.json.

Calendar list (agenda)

data-view="agenda" - upcoming events, grouped by month. Source here: an .ics file (data/sample.ics), including recurring events via RRULE.

Event list

data-view="list" - events as a card grid, uses .ncss-card instead of its own styling.

Single event

data-view="single" - one highlighted event, chosen via data-event-id (here: "conf"), or the next upcoming one if omitted.

Downloads

js/downloads.js - file list from data/downloads.json, icon/size derived automatically from type/size or the file extension.

Data format

JSON events (every field except title/start is optional):

[
  { "title": "Kickoff", "start": "2026-08-26T09:00", "end": "2026-08-26T10:30",
    "location": "Room A", "description": "...", "url": "https://..." },
  { "title": "Holiday", "start": "2026-10-03", "allDay": true }
]

.ics files (Google/Outlook/Apple exports) are supported too (data-ics instead of data-src) - see js/ics.js for the supported RRULE scope.
