Adjust colors live

Sets each base color directly as a CSS custom property on <html> - all derived steps (100/300/700/900, badges, buttons, cards ...) follow automatically, because they are computed from exactly these values via color-mix(). Light and dark stay SEPARATELY editable (a real light-dark() pair, not a fixed value) - toggle below which of the two variants the controls currently show/edit. The theme/palette buttons stay clickable but no longer affect the colors changed here until "Reset" is pressed.

--ncss-color-overlay deliberately has no control - it's a transparent rgb(0 0 0 / 45%) value; <input type="color"> can't represent transparency and would silently set the opacity to 100% when applied.

All color tokens are computed from one base color per family (color-mix() in oklch, see colors.css) - use the theme button at the top right to compare every surface in light/dark.

Cards in different colors

.ncss-card--brand/-brand-2/-neutral/-success/-warning/-danger - 100 surface + -on-soft text (the same pairing as badges), plus a colored border as an accent. This exact pattern also serves as the hint/callout/"note" box for documentation text (tip/warning/error) - no separate callout component needed, the same classes are enough.

Light/dark toggle

js/theme-toggle.js + components/theme-toggle.css set [data-theme] on <html> (takes effect via light-dark() in colors.css) and remember the choice. js/theme-toggle-early.js, loaded synchronously in the <head>, prevents a flash of the wrong mode on load. Two variants - both active here, they toggle the same state:

Icon button: light ↔ dark Cycle: system → light → dark 
<head>
  <script src="dist/js/theme-toggle-early.js"></script>   <!-- synchronous, before the CSS -->
  <link rel="stylesheet" href="dist/ncss.css">
  <script src="dist/js/theme-toggle.js" defer></script>
</head>

<button type="button" class="ncss-theme-toggle" data-ncss-theme-toggle>
  <span class="ncss-icon ncss-icon-moon ncss-theme-icon-dark" aria-hidden="true"></span>
  <span class="ncss-icon ncss-icon-sun ncss-theme-icon-light" aria-hidden="true"></span>
</button>
