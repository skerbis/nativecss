Video: crop per screen size

For <video> there is (unlike <picture> for images) NO reliable native "different file per breakpoint" - <source media="..."> was removed again from the spec and most browsers (only Safari still supports it as a legacy feature). .ncss-video--responsive-crop instead crops THE SAME video differently via object-fit - make the window narrower and the crop turns portrait.

Cover: fully cropping embeds

.ncss-img-cover (above) is enough for <img>/<video> - components/cover.css covers the one case native object-fit does NOT solve: <iframe> embeds. Two containers with the same 16:9 embed and different aspect ratios - both completely filled, no borders, no distortion: 

<div class="ncss-cover-container" style="height: 20rem;">
  <iframe class="ncss-cover" src="https://www.youtube.com/embed/..." title="..." allowfullscreen></iframe>
</div>

Hero section (image background + content on top)

.ncss-hero places content over a background image - two independent options: the content panel --transparent (text directly on the image, with a gradient scrim) or --filled (opaque card), and optionally .ncss-hero--parallax (the image scrolls slower than the content - scroll the page to try it).

1. Transparent - text directly on the image

Text right on the image

A gradient scrim (.ncss-hero-media::after) keeps it readable, whatever the subject underneath.

2. Filled - opaque card on top

Card on top

The image stays visible, but the text sits on its own opaque surface (--ncss-color-surface) instead of directly on the subject.

3. Parallax (.ncss-hero--parallax) - watch while scrolling

Parallax hero

Runs purely on animation-timeline: view() - no JS, no background-attachment: fixed (deliberately never supported on iOS Safari). Without support or with reduced motion it simply stays a static hero image like the one above.

Audio

Native <audio controls> can hardly be restyled (browser-owned controls) - .ncss-audio only ensures a consistent width, .ncss-audio-card optionally adds a title.
