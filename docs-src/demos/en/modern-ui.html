Bento grid

Spotlight

A cone of light follows the mouse pointer, and the border segment near the pointer lights up. data-ncss-spotlight on the group: one listener for all, neighbors catch the edge of the light. Without JS and with keyboard focus, the light sits in the center. components/spotlight.css + js/spotlight.js.

Default

Whole card clickable (.ncss-card--linked) - tabbing to the link shows the light too.

Command palette

<ncss-command-palette shortcut="k"> around a <dialog>: opens without JS via command="show-modal", and with JS also via a keyboard shortcut (here ⌘J / Ctrl+J, because ⌘K opens search on this website). Combobox + listbox per APG: focus stays in the field, ↑/↓ selects, Enter runs, Esc closes. The filter ignores case and accents, data-keywords supply extra terms.

Notifications

ncss.notify() or data-ncss-notify on the button. Timers pause while the pointer or focus is in the region. Errors (danger) stay until they are closed. The region lives in the top layer - notifications appear even above an open modal.

Stacked (Sonner style)

Click several times: older notifications stack behind the newest one and fan out on hover or keyboard focus.

ncss.notify("Saved", { status: "success" });
ncss.notify({ title: "Upload failed", message: "File too large",
              status: "danger", position: "top-start" });
ncss.notify("Copied", { position: "bottom-end", stack: true, timeout: 8000 });
<button type="button" data-ncss-notify="Saved" data-status="success">Save</button>
<script src="ncss/js/notification.js" defer></script>
