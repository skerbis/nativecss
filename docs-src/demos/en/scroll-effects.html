Scroll-driven effects, natively via animation-timeline: view() and (Chromium) scroll-triggered animations - JavaScript only as a small, opt-in fallback or where CSS can't reach (focus, state, events). Each effect is its own file and can be included individually. Without support and with reduced motion, everything stays perfectly readable.

Text reveal

components/text-reveal.css - text lights up as you scroll through it. Lines and flow without JS, word by word with js/text-reveal.js.

Lines (default)

Native CSS can now do what used to require an animation library: tie progress to the scroll position, without any scroll listener.

Flow (--flow)

In flow mode the brightness travels word by word across the lines in reading direction - a single gradient on an inline element.

Words (data-ncss-text-reveal)

Each word gets its own section and rises into view individually.

<p class="ncss-text-reveal">...</p>
<p class="ncss-text-reveal ncss-text-reveal--flow"><span>...</span></p>
<p class="ncss-text-reveal" data-ncss-text-reveal>...</p>

Scrollytelling

<ncss-scrolly> (components/scrolly.css + js/scrolly.js) - the step in the middle of the viewport is active and switches the media. Each step carries data-ncss-time; the ncss-scrolly-step event reports {index, time}, e.g. for a scroll-controlled video.

Last event: -

1. Starting point

Without JavaScript, all steps and images simply stack one below the other.

2. Stage

With the element, the media column sticks and one image is visible at a time.

3. Hook

data-ncss-time gives each step a time marker in seconds.

4. End

Narrow: the media sits on top, the steps scroll past below it.

Curtain sections

components/curtain.css - each section stays in place while the next one slides over it; --scale makes the covered one recede, --dim darkens it. No position: sticky - even extra-tall sections show all of their content.
