1Kopieren

Empfohlen: Release-ZIP von GitHub (nativecss-<version>.zip, nur dist/ + Lizenz, ca. 430 KB, ab v1.1.0) entpacken. Alternativ git clone https://github.com/skerbis/nativecss.git und daraus dist/ nehmen.

dist/ ins Projekt kopieren (z.B. als ncss/) und einbinden - fertig.

<link rel="stylesheet" href="ncss/ncss.css">
<link rel="stylesheet" href="ncss/theme.css">

2CDN

Direkt von jsDelivr laden, ohne Download.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@skerbis/nativecss@1/dist/ncss.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@skerbis/nativecss@1/dist/theme.css">

Für den Live-Betrieb eine feste Version angeben, z.B. @skerbis/nativecss@1.1.0.

3npm (optional)

Für Projekte, die ohnehin einen Bundler nutzen.

npm i @skerbis/nativecss

import "@skerbis/nativecss";              // JS-Einstieg
@import "@skerbis/nativecss/dist/ncss.css";    /* oder in CSS */

4Mit CMS

REDAXO 6 + fluid: das AddOn fluid bringt ein fertiges NativeCSS-Kit mit (Website → Kit → NativeCSS) - mit Blöcken, Design-Einstellungen und Frontend-Bearbeitung.

KLXM Studio: NativeCSS-Kit für KLXM Studio - demnächst.

npm ist nur ein zusätzlicher Weg - NativeCSS braucht keinen Build-Schritt. Kopieren, CDN und npm liefern dieselben Dateien - fluid und KLXM Studio bringen sie bereits mit.
