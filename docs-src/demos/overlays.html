Native Elemente (details, dialog)

Details aufklappen

Inhalt, der per nativem <details> ein-/ausgeblendet wird - kein JS nötig. Die "Box"-Optik kommt jetzt explizit von .ncss-disclosure, nicht mehr vom nackten Tag.

Natives <dialog> als .ncss-modal

Fokus-Trap, ESC zum Schließen, ::backdrop, Fade+Scale-Animation - alles vom Browser/CSS, kein JS-Modal-Framework.

3D-Varianten: perspective() als Transform-Funktion in der eigenen transform-Kette (kein perspective auf einem Elternelement nötig/wirksam, <dialog> rendert im Top Layer).

.ncss-modal--3d

Kippt beim Öffnen wie aus der Tiefe nach vorne herein, statt nur zu faden/skalieren.

.ncss-modal--3d-flip

Dreht sich beim Öffnen einmal um die eigene Hochachse herein, wie eine Karte.

.ncss-modal--3d-swing

Schwingt wie eine Tür um ein Scharnier an der linken Kante herein.

Einblendvarianten: statt der Standard-Skalierung slidet/wächst das Modal aus einer Richtung heran (langsamere, deutlich abbremsende Bezier-Kurve statt der neutralen Standardkurve).

.ncss-modal--slide-up

Schiebt sich beim Öffnen von unten herein.

.ncss-modal--slide-down

Schiebt sich beim Öffnen von oben herein.

.ncss-modal--slide-left

Schiebt sich beim Öffnen von rechts herein.

.ncss-modal--slide-right

Schiebt sich beim Öffnen von links herein.

.ncss-modal--zoom

Wächst beim Öffnen deutlicher aus der Mitte heran als der Standard-Fade.

AJAX-Modal-Router (js/modal-router.js, opt-in): Trigger-Links mit echtem href laden ihr Ziel per fetch() in ein geteiltes Modal nach, die Adresse wandert per history.pushState() mit (eigenständig öffnen):

Off-Canvas-Sidebar (eigenständig, nicht nur im Mobile-Nav)

Dasselbe .ncss-offcanvas, das die Navigation oben unterhalb 64rem Viewport-Breite nutzt - hier unabhängig davon, immer über den Button auslösbar.

Off-Canvas-Inhalt

Schiebt sich von der Kante ein (@starting-style + translate), mit Backdrop und Fokus-Trap - alles vom nativen <dialog>.

Modal, Lightbox-Variante (.ncss-modal--fullscreen .ncss-modal--dark)

Keine eigene Lightbox-Komponente mehr - nur .ncss-modal mit zwei Varianten.

Großes Bild

Lightbox-Galerie (data-ncss-lightbox)

Mehrere Bilder einer Gruppe durchblättern - Pfeiltasten, Vor/Zurück, Wischen, Zähler, Bildunterschrift. Baut auf der Modal-Lightbox oben auf (components/lightbox.css + js/lightbox.js), ohne JavaScript öffnet der Link einfach das große Bild.
