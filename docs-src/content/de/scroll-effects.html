Scroll-Effekte

Effekte, die an die Scroll-Position gekoppelt sind - nativ über animation-timeline: view() bzw. (Chromium) scroll-getriggerte Animationen. JavaScript nur als kleiner, opt-in Fallback oder dort, wo CSS nicht hinkommt (Tastatur-Fokus, Zustand, Events). Live-Demo.

Jeder Effekt ist eine eigene Datei und einzeln einbindbar (Cherry-Picking): er braucht nur colors.css/tokens.css/reset.css/base.css plus ggf. sein eigenes Script. Ohne Unterstützung, bei prefers-reduced-motion und im Druck bleibt alles normal lesbar - kein Fehlerzustand.

Reveal-Formen

helpers/reveal.css + optional js/reveal.js. Basisklasse .ncss-reveal plus genau eine Form - auf jedem Element (Bild, <video>, Sektion, Karte). Standard: scroll-gescrubbt (zurückscrollen spult zurück). .ncss-reveal--once: einmal, zeitbasiert, beim Hereinscrollen. Nach dem Reveal bleibt kein clip-path stehen - Fokus-Ringe und Schatten werden nicht beschnitten.

ModifierWirkung
--circleIris aus --ncss-reveal-x/-y (Default Mitte)
--wipe-right / -left / -up / -downKante läuft in die genannte Richtung
--inset / --split / --diagonalRechteck aus der Mitte / Vorhang zu beiden Seiten / diagonale Kante
--zoomAusschnitt öffnet sich, das Medium darin skaliert 1.15 → 1 - auf einen Wrapper setzen
--expandeingerückte, abgerundete Box wächst auf volle Größe (auf vollbreitem Element: Full-Bleed)
--fade / --slide-up / --scaleklassische Einblendungen mit derselben Mechanik (inkl. --once)
 
<img class="ncss-reveal ncss-reveal--circle" src="..." alt="...">
<figure class="ncss-reveal ncss-reveal--zoom"><img src="..." alt="..."></figure>
<section class="ncss-reveal ncss-reveal--split ncss-reveal--once" data-ncss-reveal>...</section>
<script src="ncss/js/reveal.js" defer></script>

Parameter: --ncss-reveal-start/-end (Default entry 25% / cover 45% - endet kurz vor der Viewport-Mitte), --ncss-reveal-inset, --ncss-reveal-radius, --ncss-reveal-scale, --ncss-reveal-duration (--once, 0.9s). Event ncss-reveal beim Start des JS-Pfads.

Verhältnis zu .ncss-animate-on-scroll (Animationen): das bleibt der schlanke Kurzweg (nur Einblenden/Gleiten, nur scrub). .ncss-reveal ist die größere, eigenständige Variante mit Formen, Einmal-Modus und Fallback - eigene Keyframes, keine Abhängigkeit zwischen beiden Dateien.

Reveal-Pin (Medium wächst zu Vollbild)

components/reveal-pin.css, kein JS. Gepinnte Bühne: ein Bild/Video zieht von einer Karte auf volle Viewport-Größe auf, das Intro blendet aus, ein Panel ein. Fallback: alles untereinander, Medium in 16:9. Für <video autoplay> unter reduzierter Bewegung zusätzlich js/hero-video-motion.js.

<section class="ncss-reveal-pin" aria-label="...">
  <div class="ncss-reveal-pin-stage">
    <p class="ncss-reveal-pin-intro">Überschrift</p>
    <video src="clip.mp4" muted playsinline loop autoplay poster="frame.jpg"></video>
    <div class="ncss-reveal-pin-content">...</div>
  </div>
</section>

Parameter: --ncss-reveal-pin-length (250vh), --ncss-reveal-pin-inset (32% 14% 6%), --ncss-reveal-pin-radius.

Morphing beim Scrollen

components/morph.css, kein JS. Ein großes Bild, Video oder beliebiges Element startet in voller Breite und schrumpft beim Hindurchscrollen weich auf ca. 45 % an den Rand - daneben wird Text (oder ein anderes Element) frei und gleitet herein. Oder andersrum. Technik: gepinnte Spuren in einer hohen Bühne, eine view-timeline treibt eine per @property typisierte Fortschrittszahl, daraus rechnen Größe, Radius und Einblendung.

<section class="ncss-morph" aria-label="Das Haus">
  <div class="ncss-morph-stage">
    <div class="ncss-morph-media"><img src="haus.webp" alt="..."></div>
    <div class="ncss-morph-content">
      <h3>Platz für Text</h3>
      <p>...</p>
    </div>
  </div>
</section>

<!-- Video zum Kreis, mit Pause-Schalter (video-bg.css + js/video-bg.js) -->
<section class="ncss-morph ncss-morph--circle" aria-label="...">
  <div class="ncss-morph-stage">
    <div class="ncss-morph-media" data-ncss-video-bg>
      <video muted loop playsinline preload="none"
             poster="frame.jpg" aria-hidden="true">
        <source data-src="loop.webm" type="video/webm">
      </video>
    </div>
    <div class="ncss-morph-content">...</div>
  </div>
</section>
Klasse / ParameterWirkung
.ncss-morphContainer (Container Query) - trägt Modifier und Parameter
.ncss-morph-stageBühne: im Scroll-Modus die hohe Strecke, sonst ein Zwei-Spalten-Raster
.ncss-morph-mediaSpur des Mediums - das erste Kind morpht (img, video, picture, canvas oder beliebiges Element)
.ncss-morph-contentText/Element daneben (kürzer als eine Bildschirmhöhe halten)
--startMedium wandert an den Anfang (links), Text am Ende
--reverseumgekehrt: beginnt nebeneinander, Medium wächst auf volle Breite, Text geht
--card / --circleForm-Morph zur abgerundeten Karte mit Schatten / zum Kreis
--ncss-morph-sizeEndbreite des Mediums (Default 45%)
--ncss-morph-radiusEndradius (Default --ncss-radius-lg, mit --card das Doppelte)
--ncss-morph-heightScroll-Strecke = Höhe der Bühne (Default 250vh)
--ncss-morph-gap / --ncss-morph-topAbstand Medium/Text; Versatz für eine klebende Kopfleiste (z.B. var(--ncss-topbar-height))

Fallback und Barrierefreiheit: ohne animation-timeline (z.B. Firefox), bei prefers-reduced-motion oder <html data-motion="reduce"> (Einstellungen; data-motion="full" hebt ein System-„reduzieren“ auf) und im Druck steht der Endzustand statisch da - Medium und Text nebeneinander, nichts klebt, keine hohe Strecke. In schmalen Containern (unter 40rem) steht das Medium über dem Text, ohne Morph. Der Text ist immer im DOM und lesbar; bekommt etwas in der Bühne Tastatur-Fokus, springt sie in den Endzustand. Videos: Pause-Schalter (WCAG 2.2.2) und Laden/Pausieren nach Bewegungs-Einstellung über data-ncss-video-bg + js/video-bg.js wie beim Hintergrundvideo.

Text-Reveal

components/text-reveal.css - Text startet blass und wird beim Hindurchscrollen hell. Zeilen (Default) und Fluss (--flow, ein Inline-Kind) ohne JS; Wort für Wort mit js/text-reveal.js (der Text bleibt für Screenreader identisch).

<p class="ncss-text-reveal">...</p>
<p class="ncss-text-reveal ncss-text-reveal--flow"><span>...</span></p>
<p class="ncss-text-reveal" data-ncss-text-reveal>...</p>

Parameter: --ncss-text-reveal-color, --ncss-text-reveal-from, --ncss-text-reveal-start/-end (Default cover 15% / cover 50%).

Count-up

components/count-up.css + optional js/count-up.js. Die echte, formatierte Zahl steht im DOM (Screenreader, Kopieren, ohne JS); gezählt wird in einem für Hilfstechnik stummen ::after, das am Ende zum echten Text überblendet. Während des Zählens fehlen Tausender-Trenner (counter() kennt keine).

<span class="ncss-count-up" data-ncss-count-up style="--ncss-count-to: 12500">12.500</span>
<span class="ncss-count-up" data-ncss-count-up style="--ncss-count-to: 98; --ncss-count-suffix: ' %'">98 %</span>

Parameter: --ncss-count-to (Pflicht, ganze Zahl - fehlt sie, liest das Script sie aus dem Text), --ncss-count-from, --ncss-count-prefix/-suffix, --ncss-count-duration (2s).

Marquee

components/marquee.css + optional js/marquee.js. Endlos-Laufband aus zwei identischen Gruppen (die Kopie aria-hidden + inert - das Script erzeugt sie, wenn nur eine Gruppe im Markup steht). Hält bei Hover (nur echte Zeigegeräte) und Fokus an. Für Inhalte mit Aussage einen Pause-Button setzen (WCAG 2.2.2) - das Script verdrahtet ihn. Reduzierte Bewegung: statische, wischbare Reihe.

<div id="logos" class="ncss-marquee ncss-marquee--fade" data-ncss-marquee>
  <ul class="ncss-marquee-group" role="list"><li>...</li></ul>
</div>
<button type="button" data-ncss-marquee-toggle aria-controls="logos">Laufband anhalten</button>

Modifier: --reverse, --slow, --fast, --fade, --paused. Parameter: --ncss-marquee-duration (30s), --ncss-marquee-gap.

Horizontal-Scroll

components/scroll-horizontal.css + empfohlen js/scroll-horizontal.js. Vertikales Scrollen schiebt eine Reihe seitlich durch eine sticky Bühne. Das Script passt die Sektionshöhe an die Reihe an (1px runter = 1px seitwärts, Tempo per Attributwert) und holt per Tab fokussierte Elemente ins Bild (WCAG 2.4.11) - für Reihen mit Links/Buttons Pflicht. Fallback: wischbare Snap-Reihe.

<section class="ncss-scroll-horizontal" data-ncss-scroll-horizontal aria-label="Projekte">
  <div class="ncss-scroll-horizontal-viewport">
    <div class="ncss-scroll-horizontal-track">
      <article>...</article> <article>...</article>
    </div>
  </div>
</section>

Parameter: --ncss-scroll-horizontal-length (300vh, vom Script überschrieben), --ncss-scroll-horizontal-item, --ncss-scroll-horizontal-gap, --ncss-scroll-horizontal-padding.

Scrollytelling: <ncss-scrolly>

components/scrolly.css + js/scrolly.js (Light-DOM-Custom-Element). Der Schritt, der die Auslöse-Linie kreuzt, wird aktiv (.is-active) und zeigt das Medium mit demselben Index; die Medien-Spalte klebt. Schmal: Medium oben, Schritte laufen darunter durch. Ohne JS: alles untereinander.

<ncss-scrolly line="50" style="--ncss-scrolly-top: var(--ncss-topbar-height)">
  <div class="ncss-scrolly-steps">
    <div class="ncss-scrolly-step" data-ncss-time="0"><div>...</div></div>
    <div class="ncss-scrolly-step" data-ncss-time="4.5"><div>...</div></div>
  </div>
  <div class="ncss-scrolly-media">
    <figure class="ncss-scrolly-figure">...</figure>
    <figure class="ncss-scrolly-figure">...</figure>
  </div>
</ncss-scrolly>
APIBedeutung
line (Attribut)Auslöse-Linie in % von oben (Default 50)
media-start (Attribut)Medien-Spalte links statt rechts
el.stepIndex des aktiven Schritts; Zuweisen scrollt den Schritt in die Mitte
data-ncss-time (Schritt)Zeitmarke in Sekunden - Andockpunkt für ein scroll-gesteuertes Video
Event ncss-scrolly-stepbubbelt, detail = { index, time, step, figure } (time = Zahl oder null)
 
document.querySelector("ncss-scrolly").addEventListener("ncss-scrolly-step", (e) => {
  if (e.detail.time !== null) video.currentTime = e.detail.time;
});

Curtain-Sektionen

components/curtain.css, kein JS. Jede Sektion bleibt stehen, die nächste gleitet darüber; --scale lässt die bedeckte zurückweichen, --dim dunkelt sie ab. Ohne position: sticky - überlange Sektionen scrollen erst komplett durch. Jede Sektion braucht einen blickdichten Hintergrund (z.B. .ncss-surface--* direkt auf der Sektion). Kombinierbar mit .ncss-snap-sections (Einrasten + Vorhang, siehe Vollbild-Sektionen).

<div class="ncss-curtain ncss-curtain--scale ncss-curtain--dim">
  <section class="ncss-surface--brand">...</section>
  <section class="ncss-surface--neutral">...</section>
</div>

<div class="ncss-snap-sections ncss-curtain ncss-curtain--dim">
  <section class="ncss-snap-section ncss-surface--brand">...</section>
  ...
</div>

Parameter: --ncss-curtain-height (100svh), --ncss-curtain-scale (0.88), --ncss-curtain-dim (0.45), --ncss-curtain-radius. Für eine gepinnte Bühne mit Karten statt echter Sektionen: components/scroll-stack.css (Stacked Cards).
