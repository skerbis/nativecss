App-Bausteine

Bausteine für Dashboards und Verwaltungsoberflächen - alle nativ, ohne Web Awesome, jede Datei einzeln einbindbar (braucht nur colors.css, tokens.css, reset.css, base.css). Jeder Abschnitt zeigt den Code und darunter das Ergebnis mit genau diesem Markup.

Einbindung

In ncss.css enthalten. Einzeln (Cherry-Picking) z.B.:

<link rel="stylesheet" href="ncss/components/avatar.css">      <!-- im Layer components -->
<script src="ncss/js/dropzone.js" defer></script>      <!-- nur für <ncss-dropzone> -->
<script src="ncss/js/countdown.js" defer></script>     <!-- nur für <ncss-countdown> -->
<script src="ncss/js/dismiss.js" defer></script>       <!-- nur für entfernbare Tags -->

Alles andere ist reines CSS. Dateien: components/ app-shell, avatar, tag, stat, empty-state, floating-label, segmented, rating, dropzone, spinner, kbd, countdown, back-to-top; die Größen-/Dichte-Varianten stecken in helpers/forms.css (Buttons), helpers/tables.css und components/card.css.

App-Gerüst

.ncss-app-shell: Seitenleiste, Kopfleiste, Inhalt. Die Seitenleiste ist ein natives popover - ab 48rem Container-Breite steht sie als feste Spalte da, darunter wird dasselbe Element zum Off-Canvas, das der Menü-Button per popovertarget öffnet (ESC, Klick daneben, Fokus-Rückgabe liefert der Browser). Kein JS, keine doppelte Navigation im DOM. Die Vorschau unten ist schmaler als 48rem, solange das Fenster schmal ist - Fenster verbreitern zeigt die Spalten-Variante.

Nach oben

Ein normaler Link auf #top (laut HTML-Spec auch ohne passende id der Seitenanfang). Mit Scroll-getriebenen Animationen schwebt er unten in der Ecke und blendet erst nach ~40vh Scrollweg ein - unsichtbar ist er auch nicht per Tab erreichbar. Ohne diese Fähigkeit bleibt er ein normaler Link an seiner Markup-Stelle - deshalb ans Seitenende setzen. Der schwebende Link dieser Seite ist unten rechts, sobald man ein Stück gescrollt hat - per --ncss-back-to-top-offset angehoben, weil die Ecke schon den Inspektor-Button trägt (zwei überlappende Ziele verletzen WCAG 2.5.8).

Grenze: reagiert auf das Scrollen der Seite (scroll(root)) - scrollt nur ein inneres Element (z.B. ein App-Gerüst mit eigener Scroll-Box), dort einen normalen Link verwenden.

Screenreader

Einstellungen

Reduzierte Bewegung: harter Wechsel statt Einblenden, kein sanftes Scrollen. Hochkontrast: Rahmen bleibt sichtbar.

Ohne JS

Reines CSS; ohne Scroll-getriebene Animationen ein normaler Link an seiner Markup-Stelle.
