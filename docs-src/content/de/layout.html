Layout

Wenige, komponierbare Layout-Primitive statt einer Utility-Matrix - helpers/layout.css.

Container

KlasseZweck
.ncss-containerZentrierte, breitenbegrenzte Spalte mit Seiten-Padding
.ncss-container--narrowModifier, NUR zusammen mit .ncss-container - schmalere max-width
.ncss-full-bleedBricht aus einem Container bis zum Bildschirmrand aus

Grid

.ncss-grid - automatisch responsives Grid ohne Media Queries (repeat(auto-fit, minmax(...))), Mindestbreite pro Spalte per Custom Property parametrisiert:

<div class="ncss-grid" style="--ncss-grid-min: 16rem;">...</div>

Stack & Cluster

KlasseZweck
.ncss-stackVertikaler Flex-Stapel mit gleichmäßigem Abstand
.ncss-stack--tight / --looseEngerer/weiterer Abstand als der Default
.ncss-clusterHorizontale Gruppe, umbricht automatisch (z.B. Tag-Listen, Button-Gruppen)

Ausbrechen (Bleed)

Varianten, um gezielt aus einem Container auszubrechen: .ncss-bleed-start/-end (einseitig), .ncss-bleed-half-start/-half-end (ab der Mitte), .ncss-bleed-center (symmetrisch um einen festen Betrag, --ncss-bleed-amount).
