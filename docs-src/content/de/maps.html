Karten

<ncss-map> zeigt eine interaktive Vektorkarte mit MapLibre GL (selbst gehostet unter vendor/maplibre/, BSD-3-Clause). Wichtigstes Ziel ist Datenschutz: Über das Attribut proxy laufen alle Anfragen der Karte über deinen eigenen Server - Besucher verbinden sich nie direkt mit einem Kartenanbieter. Dateien: components/map.css + js/map.js, einzeln einsetzbar (nur colors.css/tokens.css/reset.css/base.css nötig).

Live-Beispiel

Diese Doku ist eine statische Seite (GitHub Pages) ohne Server-Proxy. Die Karte unten lädt deshalb direkt von OpenFreeMap (tiles.openfreemap.org) - aber erst nach deinem Klick auf „Karte anzeigen“ (Zwei-Klick-Modus). Vorher wird nichts von Dritten geladen. Auf deiner eigenen Website setzt du stattdessen proxy, dann ist auch der Klick nicht mehr nötig.

Datenschutz: Proxy statt Drittanbieter

Eine Webkarte lädt Stil (JSON), Kacheln, Schriften (Glyphen) und Symbole (Sprites) - normalerweise direkt vom Kartenanbieter. Dabei überträgt der Browser jedes Mal die IP-Adresse des Besuchers. Mit proxy schreibt <ncss-map> jede dieser Anfragen per MapLibre-transformRequest auf deinen Server um; der holt die Daten (und kann sie cachen). Ergebnis: kein Kontakt zu Dritten, keine Einwilligung nötig, keine Cookies.

FormBeispielAus https://tiles.openfreemap.org/planet/…/1/0/0.pbf wird
Präfix (Origin wird ersetzt)proxy="/proxy/ofm/"/proxy/ofm/planet/…/1/0/0.pbf
Vorlage mit {url} (URL-kodiert)proxy="/proxy?url={url}"/proxy?url=https%3A%2F%2Ftiles.openfreemap.org%2Fplanet%2F…
Vorlage mit {host}/{path}proxy="/proxy/{host}/{path}"/proxy/tiles.openfreemap.org/planet/…/1/0/0.pbf

Umgeschrieben wird standardmäßig jede fremde Origin (alles außer der eigenen Seite und dem Proxy selbst); proxy-origins="tiles.openfreemap.org" beschränkt das auf bestimmte Server. Die Präfix-Form passt, wenn alle Daten von einem Server kommen (OpenFreeMap: Stil, TileJSON, Kacheln, Glyphen und Sprites liegen alle auf tiles.openfreemap.org). Verweist dein Stil auf mehrere Server, nimm die {url}-Vorlage.

nginx

# /proxy/ofm/… -> https://tiles.openfreemap.org/… (mit Cache)
proxy_cache_path /var/cache/nginx/ofm levels=1:2 keys_zone=ofm:10m max_size=2g inactive=30d;

server {
  # …
  location /proxy/ofm/ {
    proxy_pass https://tiles.openfreemap.org/;
    proxy_ssl_server_name on;
    proxy_set_header Host tiles.openfreemap.org;
    proxy_set_header Cookie "";
    proxy_set_header X-Forwarded-For "";      # IP des Besuchers NICHT weitergeben
    proxy_hide_header Set-Cookie;
    proxy_cache ofm;
    proxy_cache_valid 200 1d;
    add_header X-Cache $upstream_cache_status;
  }
}

PHP (eine Datei, mit Allowlist)

<?php
// proxy.php - Aufruf: /proxy.php?url={url}  →  <ncss-map proxy="/proxy.php?url={url}">
// Skizze: vor dem Produktiveinsatz Cache, Größenlimit und Rate-Limit ergänzen.
$allow = ['tiles.openfreemap.org'];               // NUR diese Hosts - sonst offenes Relay
$url   = (string) ($_GET['url'] ?? '');
$parts = parse_url($url);
if (($parts['scheme'] ?? '') !== 'https' || !in_array($parts['host'] ?? '', $allow, true)) {
    http_response_code(403);
    exit;
}
$ch = curl_init($url);
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_FOLLOWLOCATION => false,
    CURLOPT_TIMEOUT        => 15,
    CURLOPT_USERAGENT      => 'site-map-proxy',     // keine Daten des Besuchers weiterreichen
]);
$body = curl_exec($ch);
$code = curl_getinfo($ch, CURLINFO_RESPONSE_CODE) ?: 502;
$type = curl_getinfo($ch, CURLINFO_CONTENT_TYPE) ?: 'application/octet-stream';
http_response_code($code);
header('Content-Type: ' . $type);
header('Cache-Control: public, max-age=86400');
echo $body;

Wichtig ist die Allowlist: Ein Proxy, der beliebige URLs abruft, wäre ein offenes Relay. Liefert der Proxy Stil-JSON mit bereits umgeschriebenen Adressen aus, ist das ebenfalls in Ordnung - Adressen auf der eigenen Seite bzw. dem Proxy werden nicht noch einmal umgeschrieben.

Fertig eingebaut: Das REDAXO-AddOn fluid bringt einen Karten-Proxy für OpenFreeMap schon mit (/proxy/ofm/…, mit Cache und Gebietsbegrenzung) - dort genügt proxy="/proxy/ofm/".

Ersatzinhalt und Zwei-Klick-Modus

Was du in <ncss-map> schreibst - Adresse, Wegbeschreibung, ein Link zu OpenStreetMap - ist der Ersatzinhalt. Er ist sichtbar ohne JavaScript, solange die Karte noch nicht geladen ist und falls das Laden scheitert (dann mit dem Hinweis „Die Karte konnte nicht geladen werden.“). Das Element ist also nie leer. Erst wenn die Karte fertig gezeichnet ist, liegt sie darüber; der Ersatzinhalt bleibt für Screenreader im Baum und erscheint bei Tastatur-Fokus auf einem Link darin unten über der Karte. Mit fallback="below" bleibt er dauerhaft sichtbar unter der Karte.

Lazy Loading: MapLibre (rund 1,1 MB) wird erst geladen, wenn die Karte in die Nähe des sichtbaren Bereichs scrollt. Bis dahin reserviert ein ruhiges Raster die Fläche, nichts springt.

Zwei-Klick-Modus (consent): Statt automatisch zu laden, zeigt die Karte einen kurzen Datenschutz-Hinweis und den Button „Karte anzeigen“. Ohne proxy nennt der Hinweis den Kartenserver und dass die IP-Adresse übertragen wird; mit proxy sagt er, dass dein Server die Daten holt. privacy-url ergänzt einen Link zur Datenschutzerklärung. Meldet das Gerät „Datensparen“ (Save-Data), ist der Modus automatisch an - so lädt niemand ungefragt ein Megabyte Karte.

Barrierefreiheit, Dunkelmodus, Bewegung

  • Die Karte ist eine benannte Region („Karte: Tollensesee“); die Kartenfläche selbst ist fokussierbar und erklärt ihre Tastenbelegung, die Markierung hat ein aria-label. Fokus ist an Karte, Buttons und Links deutlich sichtbar.
  • Eine Karte ist für Screenreader kaum nutzbar - deshalb ist der Ersatzinhalt die eigentliche Text-Alternative: Adresse und Link gehören immer hinein.
  • Dunkelmodus: Ist <html data-theme-resolved="dark"> (bzw. data-theme="dark" oder das System dunkel), lädt die Karte style-url-dark - live beim Umschalten, auch über <ncss-preferences>.
  • Bewegung reduzieren (prefers-reduced-motion oder <html data-motion="reduce">): keine Kamerafahrten, keine Überblendung, view3d startet direkt geneigt.
  • Forced Colors: Systemfarben für Rahmen, Hinweis und Button, die Markierung bleibt sichtbar.
