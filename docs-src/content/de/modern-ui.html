Moderne UI

Acht moderne Bausteine - jeder als eigene CSS-Datei (plus höchstens ein Script), lauffähig allein mit colors.css/tokens.css/reset.css/base.css. Interaktive Teile sind Light-DOM-Custom-Elements um natives Markup: ohne JavaScript bleibt immer ein sinnvoller Grundzustand.

Bento-Raster

.ncss-bento ist sein eigener Container: wird das Raster zu schmal für eine Spannweite (.ncss-col-span-2/-3), fällt sie weg, statt seitlich überzulaufen. Jede Kachel ist ebenfalls ein Container - in sehr schmalen Kacheln werden Überschriften kleiner und trennen nach Sprachregeln (lang setzen). Zeilen wachsen mit dem Inhalt (minmax(--ncss-bento-row-height, auto)). Vorlagen ohne Klassen an den Kacheln: .ncss-bento--hero (1. Kachel 2×2, 4. hoch, jede 6. ab der 5. breit) und .ncss-bento--mosaic.

<div class="ncss-bento ncss-bento--hero">
  <article class="ncss-card ncss-border ncss-radius-lg">...</article>
  <article class="ncss-card ncss-border ncss-radius-lg">...</article>
</div>

Schwellen: 1 Spalte unter 26rem, Spannweite 3 wird unter 40rem zur vollen Zeile - passend zum Default --ncss-bento-min: 12rem. grid-auto-flow: dense ändert nur die visuelle, nicht die Tab-Reihenfolge.

Spotlight

Ein Lichtkegel folgt dem Mauszeiger, dazu leuchtet das Rand-Segment nahe am Zeiger auf (Masken-Ring-Technik wie .ncss-glow-border). data-ncss-spotlight an einer Gruppe: ein Listener für alle Flächen, Nachbarn fangen den Rand des Lichts auf. Touch wird ignoriert.

<div class="ncss-grid" data-ncss-spotlight>
  <article class="ncss-card ncss-spotlight">...</article>
  <article class="ncss-card ncss-spotlight ncss-spotlight--strong">...</article>
</div>
<script src="ncss/js/spotlight.js" defer></script>

Tokens: --ncss-spotlight-color, --ncss-spotlight-border, --ncss-spotlight-size (24rem). Attribut data-reach (px, Default 160) für die Nachbar-Reichweite.

Vorher/Nachher-Vergleich

<ncss-compare> legt einen echten <input type="range"> über zwei Bilder: Maus, Touch (waagerecht ziehen, senkrecht scrollt weiter), Tastatur und Screenreader kommen vom Browser. Das Script setzt nur --ncss-compare-position und aria-valuetext ("30 % vorher").

<ncss-compare style="--ncss-compare-ratio: 4 / 3">
  <img class="ncss-compare-before" src="vorher.jpg" alt="Küche vor der Renovierung">
  <img class="ncss-compare-after" src="nachher.jpg" alt="Küche nach der Renovierung">
  <span class="ncss-compare-label" aria-hidden="true">Vorher</span>
  <span class="ncss-compare-label ncss-compare-label--end" aria-hidden="true">Nachher</span>
  <input class="ncss-compare-range" type="range" min="0" max="100" value="50"
         aria-label="Trennlinie verschieben: links vorher, rechts nachher">
</ncss-compare>
<script src="ncss/js/compare.js" defer></script>

Attribut value-text (z.B. "{n} % alt"), Event ncss-compare-change (detail.value), Eigenschaft el.value. Ohne JS ist der Regler ausgeblendet (ein Regler, der die Bilder nicht mitnimmt, wäre irreführend).

Aufklapp-Panels

Reines CSS: das überfahrene oder fokussierte Panel wächst (flex-grow), sonst das aktive (.ncss-expand-panel--active oder aria-current). Unter 36rem Containerbreite stapeln sich die Panels und wachsen in der Höhe. Panels sind Links oder Buttons - per Tab erreichbar.

<div class="ncss-expand-panels">
  <a class="ncss-expand-panel ncss-expand-panel--active" href="/alpen">
    <span class="ncss-expand-panel-media"><img src="alpen.jpg" alt=""></span>
    <span class="ncss-expand-panel-title">Alpen</span>
    <span class="ncss-expand-panel-body">Sechs Touren über 3000 m.</span>
  </a>
</div>

Tokens: --ncss-expand-height (24rem), --ncss-expand-grow (4), --ncss-expand-collapsed/-expanded (gestapelte Höhen).

Befehlspalette

<ncss-command-palette> um einen <dialog class="ncss-command">. WAI-ARIA Combobox + Listbox wie bei der Live-Suche: Fokus bleibt im Feld, ↑/↓ wählt, Enter führt aus (Link folgt seinem href, Button wird geklickt), Esc schließt. Das Kürzel ⌘K / Strg+K ist opt-in per shortcut="k".

<button type="button" command="show-modal" commandfor="cmd">Befehle</button>
<ncss-command-palette shortcut="k">
  <dialog id="cmd" class="ncss-command" aria-label="Befehlspalette" closedby="any">
    <div class="ncss-command-search">
      <input class="ncss-command-input" type="text" aria-label="Befehl suchen">
    </div>
    <div class="ncss-command-list" aria-label="Befehle">
      <div class="ncss-command-group">
        <p class="ncss-command-group-label">Seiten</p>
        <a class="ncss-command-item" href="/" data-keywords="start home">Startseite</a>
        <button class="ncss-command-item" type="button">Dunkles Design</button>
      </div>
    </div>
    <p class="ncss-command-empty" hidden>Keine Treffer</p>
  </dialog>
</ncss-command-palette>
<script src="ncss/js/command-palette.js" defer></script>

Events: ncss-command-select (abbrechbar, detail.item), ncss-command-show/-hide. Methoden: show(), hide(), toggle(), filter(text). Fehlt natives command/commandfor, öffnet das Script den Dialog selbst - js/command-fallback.js ist nicht nötig.

Hovercards

<ncss-hovercard>: erstes Kind ist der Link, .ncss-hovercard die Karte (popover="hint", Top Layer, Anchor Positioning mit automatischem Umklappen). Mit interestfor (Chromium) übernimmt der Browser Hover, Fokus, Verzögerung, Esc und Long-Press ganz ohne JS. Sonst öffnet das Script nach 400 ms bei Hover oder Tastatur-Fokus, hält die Karte offen, solange Zeiger oder Fokus darin sind (WCAG 1.4.13), und schließt mit Esc. Ohne Anchor Positioning rechnet es die Position selbst.

<ncss-hovercard>
  <a href="/team/ada" interestfor="hc-ada">Ada Lovelace</a><span id="hc-ada" class="ncss-hovercard" popover="hint">
    <span class="ncss-hovercard-header">
      <span class="ncss-hovercard-avatar" aria-hidden="true">AL</span>
      <span><strong class="ncss-hovercard-title">Ada Lovelace</strong>
            <span class="ncss-hovercard-meta">Mathematikerin</span></span>
    </span>
    <span class="ncss-hovercard-text">...</span>
  </span></ncss-hovercard>
<script src="ncss/js/hovercard.js" defer></script>

In Fließtext ein <span> als Karte verwenden und keinen Zeilenumbruch zwischen </a>, Karte und </ncss-hovercard> lassen - sonst bleibt ein Leerzeichen vor dem folgenden Satzzeichen. Attribute delay/hide-delay (ms), Events ncss-hovercard-show/-hide. Die Karte nur für Zusatzinfos nutzen - Touch-Nutzer ohne interestfor sehen sie nicht.

Benachrichtigungen

ncss.notify() erzeugt eine Meldung in einer <ncss-toast-region> (entsteht automatisch, eine pro Position). Statusfarben brand/success/warning/danger, sechs Positionen (top-start … bottom-end), Schließen-Button, Timer mit Pause bei Hover, Fokus oder Hintergrund-Tab (Restzeit läuft weiter). Fehler bleiben standardmäßig stehen. Die Region ist aria-live="polite", danger/warning zusätzlich role="alert"; als popover="manual" liegt sie im Top Layer, auch über modalen Dialogen.

ncss.notify("Gespeichert", { status: "success" });
ncss.notify({ title: "Upload fehlgeschlagen", message: "Datei zu groß", status: "danger" });
ncss.notify("Kopiert", { position: "bottom-end", stack: true, timeout: 8000 });
// ohne globales Objekt:
document.dispatchEvent(new CustomEvent("ncss-notify", { detail: { message: "Hallo" } }));
<button type="button" data-ncss-notify="Gespeichert" data-status="success">Speichern</button>

<!-- serverseitig, bleibt ohne JS einfach stehen -->
<ncss-toast-region position="top-end" stack>
  <div class="ncss-notification ncss-notification--success" data-timeout="6000">
    <p class="ncss-notification-title">Gespeichert</p>
    <p>Deine Änderungen sind online.</p>
  </div>
</ncss-toast-region>
<script src="ncss/js/notification.js" defer></script>

Gestapelt (Attribut stack bzw. Option stack: true): ältere Meldungen liegen als Stapel hinter der neuesten und fächern sich bei Hover oder Tastatur-Fokus auf. Nachrichtentext wird immer als Text eingefügt (kein HTML) - für eigenes Markup einen DOM-Knoten übergeben.

Aurora & Mesh

Weiche, treibende Farbfelder aus den Markenfarben hinter einer Sektion - radiale Verläufe, bewegt nur per transform (kein Blur-Filter). Text bleibt --ncss-color-text auf einer mit der Seitenfläche gemischten Farbe, in Hell und Dunkel.

<section class="ncss-aurora">...</section>
<section class="ncss-aurora ncss-aurora--vivid">...</section>
<section class="ncss-mesh">...</section>
<section class="ncss-mesh ncss-mesh--static">...</section>

Tokens: --ncss-aurora-1/-2/-3, --ncss-aurora-opacity, --ncss-aurora-speed (14s), --ncss-mesh-speed (28s). Bei reduzierter Bewegung statisch, in Forced Colors aus.

Befehlspalette als Suche (Suchmodus)

Für große Listen - etwa eine Website-Suche - lädt <ncss-command-palette src="suche.json"> die Einträge aus einer JSON-Datei, sobald die Palette zum ersten Mal öffnet, und rendert Treffer erst beim Tippen: gerankt (Titel-Anfang vor Titel vor Stichwort/Text), je Gruppe begrenzt (limit, Default 8), die Gruppe mit dem besten Treffer zuerst, Suchbegriffe als <mark> hervorgehoben. Kein Server, keine Bibliothek - die Suche oben auf dieser Website ist genau das (Index aus docs-src/build.mjs).

<button type="button" command="show-modal" commandfor="suche">Suchen <kbd data-ncss-command-key>Strg K</kbd></button>
<ncss-command-palette shortcut="k" slash src="suche.json" limit="7">
  <dialog id="suche" class="ncss-command" aria-label="Suchen" closedby="any">
    <div class="ncss-command-search"><input class="ncss-command-input" type="search" aria-label="Suchen"></div>
    <div class="ncss-command-list" aria-label="Treffer">...Vorschläge (auch ohne JS)...</div>
    <p class="ncss-command-empty" hidden>Keine Treffer</p>
  </dialog>
</ncss-command-palette>
{ "groups": [{ "id": "pages", "label": "Seiten" }, { "id": "classes", "label": "Klassen" }],
  "items":  [{ "g": "pages", "t": "Karten", "u": "de/cards.html", "h": "Inhalt", "s": "Kurzer Textauszug", "k": "card teaser" }] }
Attribut / APIBedeutung
srcJSON-Index für den Suchmodus; u gilt relativ zur JSON-Datei.
limitHöchstzahl Treffer je Gruppe (Default 8).
slashZusätzlich / als Kürzel (nicht, während ein Eingabefeld Fokus hat).
data-ncss-command-keyElement bekommt den passenden Kürzel-Text (⌘K bzw. Strg K).
.ncss-command-item-title / -snippetZweizeiliger Treffer: Titel und einzeiliger Textauszug.
