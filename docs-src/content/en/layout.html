Layout

A few composable layout primitives instead of a utility matrix - helpers/layout.css.

Container

ClassPurpose
.ncss-containerCentered, width-limited column with side padding
.ncss-container--narrowModifier, ONLY together with .ncss-container - narrower max-width
.ncss-full-bleedBreaks out of a container to the edge of the screen

Grid

.ncss-grid - automatically responsive grid with no media queries (repeat(auto-fit, minmax(...))), minimum column width parametrized via a custom property:

<div class="ncss-grid" style="--ncss-grid-min: 16rem;">...</div>

Stack & Cluster

ClassPurpose
.ncss-stackVertical flex stack with even spacing
.ncss-stack--tight / --looseTighter/looser spacing than the default
.ncss-clusterHorizontal group, wraps automatically (e.g. tag lists, button groups)

Bleed

Variants for deliberately breaking out of a container: .ncss-bleed-start/-end (one side), .ncss-bleed-half-start/-half-end (from the middle), .ncss-bleed-center (symmetric by a fixed amount, --ncss-bleed-amount).
