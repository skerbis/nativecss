GPU Compositing Hint

Opt-in, translateZ(0): .ncss-gpu-boost promotes an element onto its own compositor layer - against jank on frequently animated/scrolled elements with expensive repaints. Uses the standalone transform property, combinable with .ncss-hover-lift/-grow/-press (which use translate/scale, not transform) without conflict. Deliberately NOT applied automatically - every additional compositor layer costs graphics memory, use it targeted only where jank is actually visible. For an element that already uses transform itself (e.g. .ncss-hero--parallax), set the --ncss-gpu-hint token directly inside its own transform declaration instead - two transform declarations on the same element would otherwise overwrite rather than combine.
