Component Reference

Every component has a detailed markup comment directly in its .css file under components/ - this is just the quick reference. Live examples in the demo pages.

Navigation & Structure

FileClassesShort description
topbar.css.ncss-topbar, -inner, -brand, -actions (+ --transparent)Header bar, grows instead of overflowing when the navigation wraps. --transparent for a topbar over a hero, usually combined with .ncss-glass as a separate background element.
nav.css.ncss-nav, -toggle, -panel, -list, -item, -dropdown (+ --nested), -submenu (+ --mega), -mega-col, -mega-heading, --treeHorizontal nav (collapses to off-canvas at 64rem) + vertical tree variant. Dropdowns/mega menu via <details>/<summary>, no hover bug on touch. Current page: aria-current="page" on the respective link.
off-canvas.css.ncss-offcanvas (+ --start/--end), -headerSide-sliding panel, native <dialog>. -header reserves space next to the absolutely-positioned .ncss-dialog-close for a heading inside the panel (otherwise they overlap)
breadcrumb.css.ncss-breadcrumbNative <nav><ol>, ::before-generated separators
footer.css.ncss-footer, -inner, -bottomPage footer scaffold
 
<nav class="ncss-nav">
  <ul class="ncss-nav-list">
    <li class="ncss-nav-item"><a href="/" aria-current="page">Home</a></li>
    <li class="ncss-nav-item"><a href="/about">About</a></li>
  </ul>
</nav>

Dialogs & Disclosure

modal.css.ncss-modal, -header, -footer (+ --fullscreen, --dark, --3d)Centered dialog modal; --fullscreen+--dark yields a lightbox. --3d tilts in from depth on open.
dialog-close.css.ncss-dialog-closeShared close button for modal/off-canvas/nav panel
disclosure.css.ncss-disclosureFAQ-box look for <details>/<summary>

  <button type="button" class="ncss-dialog-close" command="close" commandfor="d" aria-label="Close">
    <span class="ncss-icon ncss-icon-close" aria-hidden="true"></span>
  </button>
  <div class="ncss-modal-header"><h3>Title</h3></div>
  <div class="ncss-modal-body">Content</div>
</dialog>
<button type="button" command="show-modal" commandfor="d">Open</button>

Cards & Content

card.css.ncss-card-container, .ncss-card, -media, -header, -body, -footer (+ --flush, --transparent, --linked, --horizontal, --horizontal-end, color variants)Card with no built-in border/corners/shadow (see Design Tokens). Color variants also double as a hint/callout box (tip/warning/error).
split.css.ncss-split-container, .ncss-split (+ --align-start/-end/-stretch), -media, -contentText next to an image, see Landing Page Blocks
tile.css.ncss-tile (+ --muted/--brand/--brand-2)Full-width color-block sections (UIkit tiles), see Landing Page Blocks
accordion-split.css.ncss-accordion-split-container, .ncss-accordion-split, -list, -item, -body, -media, -media-mobileTransforming accordion (known from apple.com), fully native with no JS, see Landing Page Blocks
badge.css.ncss-badge (+ color variants), .ncss-badge-icon (+ --lg)Status/category chips; -icon variant as a circle/square around an icon instead of a text pill
placeholder.css.ncss-placeholder (+ --surface)Gray placeholder for demo/prototype content
hero.csssee MediaImage background section with content on top, optional parallax

</article>

Scroll & Animation

slideshow.css.ncss-slideshow, -track (+ --no-scrollbar), -item (+ --peek)Scroll-snap carousel, no JS
sparkline.css.ncss-sparkline, -area, -dotSmall inline data line. Coordinates by hand OR computed by components/sparkline.js (opt-in) from data-values/data-src, including an accessible hidden table with the real values
scroll-progress.css.ncss-scroll-progress (+ --vertical, --end)Reading progress bar, animation-timeline: scroll()
scroll-stack.css.ncss-stack-section, .ncss-stack-stage, .ncss-stack-cardPinned stage, cards slide over one another into a fanned stack while scrolling ("pinned scrollytelling"). view-timeline-based, opt-in JS fallback for Firefox/older Safari: components/scroll-stack-fallback.js, see Web Awesome Bridge
roadmap.css.ncss-roadmap, -line, -list, -item, -dot, -cardMilestone list with a self-drawing progress line on scroll

Effects

effects.css.ncss-glow-borderRotating gradient ring via ::before + mask-composite: exclude
.ncss-glow-pulsePulsing box-shadow
.ncss-glassGlassmorphism (backdrop-filter, @supports-guarded). Don't apply to an element with Floating UI descendants (<wa-dropdown> and similar) - backdrop-filter creates a new containing block for position:fixed
.ncss-stamped (+ --press)Hairline-thin, two-tone "engraved" border, works on any surface
.ncss-grainFine SVG noise via ::after + mix-blend-mode

Purely decorative, deliberately optional - none of these classes are part of .ncss-card/-btn.
