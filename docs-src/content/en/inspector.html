Code Inspector

Every page of this website has a floating Inspect switch at the bottom right (keyboard: Alt+I, Mac ⌥I). Turn it on and click any element - the inspector shows how it is built.

What it shows

  • HTML of the element, cleaned up and indented - with a copy button.
  • An explanation of every ncss- class, data-ncss- attribute and <ncss-…> element, linking to the matching docs section.
  • The defining file in dist/ plus a short description of that file.
  • JavaScript: which script from dist/js/ belongs to the data-ncss- attributes.
  • Cherry-picking: the @import lines for your own slimmed-down ncss.css with exactly this building block.

Usage

  • Ancestor bar and Parent ↑: jump from the clicked button to the whole card.
  • Esc leaves the mode, so does a second click on Inspect.
  • Works on docs pages and on every example website.

Where the explanations come from

When the website is built (node docs-src/build.mjs), the "Class | Purpose" tables of all docs pages and the first sentence of every file comment in dist/ are collected into docs/class-index.en.json (and .de.json). The inspector loads that file the first time it is switched on - without it, it shows everything except the explanations. A new class therefore gets its explanation automatically as soon as it appears in a class table in the docs. File descriptions are currently German only.

The inspector is a tool of this website (demo/assets/js/inspector.js), not part of dist/.
