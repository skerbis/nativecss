Media

Image, video, audio and hero sections - helpers/media.css, components/video.css, components/audio.css, components/hero.css.

Images

ClassPurpose
.ncss-ratio-video/-square/-portraitaspect-ratio via custom property, no padding hack needed
.ncss-img-cover / .ncss-img-containobject-fit, -cover including --ncss-focus-point
.ncss-img-rounded / .ncss-img-circleCorner radius / full circle shape
.ncss-img-dim-in-darkDims in dark mode (icons/graphics with a hard light background)
.ncss-figureFigure+figcaption layout (typography already sits in base.css)

Art direction: <picture><source media="..."> reliably loads a different image file per breakpoint - the native, correct tool for this.

Video & Audio

.ncss-videoAspect-ratio wrapper for <video>
.ncss-video--responsive-cropDifferent crop of the same file via object-fit + breakpoint - there's no reliable native "different file per breakpoint" for video, unlike images (<source media> there is now just Safari legacy)
.ncss-audioConsistent width for <audio controls>
.ncss-audio-cardAudio player with a title

Hero Section

Image background with content on top, components/hero.css.

<section class="ncss-hero">
  <div class="ncss-hero-media" style="background-image: url(image.jpg)"></div>
  <div class="ncss-hero-content ncss-hero-content--filled">
    <h2>Heading</h2>
    <p>Text...</p>
  </div>
</section>
.ncss-heroWrapper, min-height: 22rem, overflow: clip
.ncss-hero-mediaIts own layer for the background image (including a readability scrim) - always set background-image inline, never via a custom property, see Known Limitations
.ncss-hero-content--transparentText directly on the image (default)
.ncss-hero-content--filledText on an opaque card on top
.ncss-hero--parallaxImage moves slower than the content while scrolling, via animation-timeline: view() - no JS, no background-attachment: fixed (deliberately never supported on iOS Safari)
