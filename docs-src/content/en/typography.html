Typography

Extends base.css with classes for cases where a tag alone isn't enough - helpers/typography.css.

Size & Color

ClassPurpose
.ncss-text-sm/base/md/lg/xlFont size
.ncss-text-muted/brand/brand-2/neutral/success/warning/dangerText color
.ncss-text-inheritcolor: inherit - for text on a colored surface
.ncss-text-light/-dark (+ -100/-300/-700/-900)Forced light/dark text, theme-independent - see Colors

Alignment & Wrapping

.ncss-text-center/start/end/justifyText alignment
.ncss-text-balance / .ncss-text-prettytext-wrap: balance/pretty
.ncss-truncateSingle-line truncation with ellipsis
.ncss-clamp-lines (+ --ncss-clamp-lines)Multi-line truncation, modern CSS instead of JS
.ncss-hyphenatehyphens: auto (needs a correct lang attribute)

Drop Cap & Multi-column Text

.ncss-drop-cap (+ --sm/--lg/--light/--brand)Initial letter via initial-letter (+ -webkit- prefix for Safari)
.ncss-columns (+ --ncss-columns-width)Multi-column body text, column-width-based
.ncss-pull-quoteHighlighted quote, column-span: all inside .ncss-columns
.ncss-text-boxed"Highlighter" look across multiple lines (box-decoration-break: clone) - needs display:inline, never nest directly inside .ncss-stack/-cluster/-grid

Other

.ncss-eyebrow (kicker above a heading), .ncss-lead-quote (left accent border), .ncss-list--dot (custom bullet points), .ncss-tracking-tight/normal/wide/wider/widest (letter spacing), .ncss-nums-tabular/-oldstyle (font-variant-numeric).
