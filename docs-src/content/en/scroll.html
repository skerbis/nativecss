Full-screen Sections

.ncss-snap-sections + .ncss-snap-section (+ --scrollable) - the classic "fullpage" pattern, section by section, entirely via Scroll Snap. .ncss-scroll-snap-x can be nested inside a section for a horizontal sub-flow.

<div class="ncss-snap-sections">
  <section class="ncss-snap-section">Section 1</section>
  <section class="ncss-snap-section">Section 2</section>
</div>

For pinned, overlapping cards instead of separate sections: see Component Reference (components/scroll-stack.css) - a different technique, there each section gets NO scroll segment of its own, instead a stage stays pinned.

Visibility

helpers/visibility.css: .ncss-hidden, .ncss-invisible, .ncss-print-only, .ncss-screen-only, .ncss-reveal-on-hover, .ncss-hide-below-md/-from-md (a fixed viewport breakpoint) plus their container-based counterparts .ncss-hide-below-container-*/-from-container-* (react to the width of the parent .ncss-container, not the viewport - details under Layout).

Scroll shadows (new)

helpers/scroll-shadow.css shows a soft shadow at the edge of a scrollable area - only as long as there is more to see in that direction. At the start there is none in front, at the end none behind, and if everything fits there is none at all. Pure CSS: a scroll-driven animation (animation-timeline: scroll(self)) controls the opacity; browsers without it and reduced motion use the classic background-attachment: local trick. The shadow sits BEHIND the content and is faint (12 % of the text color) - nothing is covered, and even muted text keeps more than 4.5:1 contrast at the darkest point. Opt-in: existing tables do not change. For photos in the slideshow there is .ncss-slideshow--shadow.

Class / variablePurpose
.ncss-scroll-shadowShadows left/right (horizontal) - e.g. added to .ncss-table-scroll
.ncss-scroll-shadow--blockAdditionally: top/bottom (vertical), sets overflow-y: auto
--ncss-scroll-shadow-sizeWidth or height of the shadow (default 1rem)
--ncss-scroll-shadow-colorShadow color (default 12 % of the text color, light/dark aware)
--ncss-scroll-shadow-coverFallback path only: color of the surface below (default page background) - set it on cards or colored areas
--ncss-scroll-shadow-max-height--block only: maximum height of the area

Accessibility: The shadow is purely additional information ("there is more here") and changes neither content nor operation. As always, the scroll area itself needs role="region", aria-label and tabindex="0" so it can be scrolled by keyboard (WCAG 2.1.1). In forced-colors mode the shadow is dropped, with reduced motion the non-animated fallback applies.
