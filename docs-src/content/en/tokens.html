Motion

TokenValue
--ncss-motion-duration-fast100ms - fast entry into :active states
--ncss-motion-duration200ms - normal transitions
--ncss-motion-duration-slow400ms
--ncss-motion-easingcubic-bezier(0.4, 0, 0.2, 1)
--ncss-motion-easing-emphasizedcubic-bezier(0.16, 1, 0.3, 1) - pronounced decelerating curve for elements ENTERING the view (e.g. .ncss-modal--slide-up), best paired with -duration-slow

Tied to prefers-reduced-motion rather than hard-coded to 0 - base.css respects the setting globally.

Breakpoints & Container Query Thresholds

A fixed convention, not usable as var() (media/container queries don't accept custom properties in the condition itself) - documented as a comment in tokens.css. Breakpointless remains the default approach, fixed breakpoints a deliberately sparingly used escape hatch, e.g. for the nav collapse at 64rem.
