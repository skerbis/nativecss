Timeline & Steps

Two components for sequences: the timeline tells what happened when; the stepper shows how far a process has got. Both switch between narrow and wide layouts with container queries and need no JavaScript.

Timeline (new)

components/timeline.css - a calm, vertical timeline for company history, changelogs or project progress: a date, a dot or icon as marker, the current entry highlighted (aria-current). With .ncss-timeline--alternate entries alternate left/right from 40rem container width - in a narrow column it automatically stays single-column. Needs only colors/tokens/reset/base.

How it differs: .ncss-roadmap (Scroll effects) is the scroll-animated variant without dates/icons; .ncss-list--steps (Lists) is a numbered how-to without states.

  1. April 2019

    Founded in Leipzig

    Three people in a backyard office, first project for a coffee roastery.

  2. September 2021

    First own product

    The booking tool goes live and reaches 400 customers within three months.

  3. February 2024

    Team grows to 25

    New office, second location in Vienna.

  4. Today · November 2026

    Version 1.1 ships

    Accessible from the start, no build step at all.

  5. 2027 (planned)

    Third location

    Not decided yet: Zurich or Prague.

Single column and compact, e.g. in a sidebar: <ol class="ncss-timeline ncss-timeline--compact" role="list">. The live area above is wide enough for the alternating layout; on a phone you see the single-column form.

ClassPurpose
.ncss-timelineThe list (<ol role="list">), also the container for the container query
.ncss-timeline-itemOne entry; draws the line segment to the next one
.ncss-timeline-markerEmpty = dot on the line; with an icon/text = filled circle. Always aria-hidden="true"
.ncss-timeline-contentText column
.ncss-timeline-date / -titleDate (<time datetime>) and heading
[aria-current]Current entry: filled marker with a second ring, date in brand colour
.ncss-timeline-item--mutedPlanned/secondary: dashed dot, muted text
.ncss-timeline--alternateAlternates left/right from 40rem container width
.ncss-timeline--compactTighter spacing, smaller markers
--ncss-timeline-gap / -line-color / -marker-color / -ringGap, line, marker and ring colour

Accessibility

Keyboard

KeyAction
-Not interactive; links inside follow the normal tab order.

Screen reader

Ordered list with role="list" and one heading per entry - the timeline can be skimmed with heading navigation. <time datetime> carries the machine-readable date. aria-current announces "current"; markers and icons are aria-hidden. In the alternating layout the reading order stays the markup order (top to bottom), only the side changes.

Preferences

Current and planned differ in shape (filled with a double ring vs. dashed), not only in colour. Forced colours: markers get a system-colour border, the current entry uses Highlight. No motion - for the scroll-animated variant see Roadmap.

Without JS

Pure CSS.

Progress steps (stepper) (new)

components/stepper.css - progress in steps for order status, form wizards or onboarding, with three states: done, current (aria-current="step") and upcoming. Horizontal as soon as the container is at least 36rem wide, vertical below that - no viewport breakpoint. Needs colors/tokens/reset/base, plus helpers/a11y.css for the hidden state text.

  1. Ordered (done) 16 Nov
  2. Paid (done) 16 Nov
  3. Shipped on its way with DHL
  4. Delivered expected Fri

ClassPurpose
.ncss-stepperThe list (<ol role="list" aria-label>), also the container; horizontal from 36rem
.ncss-stepper-stepOne step (upcoming: thin ring, dashed line)
.ncss-stepper-step--doneDone: filled circle with a check, solid line
[aria-current="step"]Current step: thick ring, bold text
.ncss-stepper-step--errorFailed: exclamation mark in danger colour
.ncss-stepper-label / -metaLabel (may be an <a>) and extra line (date, hint)
.ncss-stepper--verticalAlways vertical, e.g. for many steps
--ncss-stepper-marker / -colorMarker size (2rem) and colour of done/current steps

Accessibility

Keyboard

KeyAction
TabOnly links in done steps are tab stops (back to an earlier step).

Screen reader

aria-current="step" announces the current step, "(done)" is hidden text in the label (.ncss-visually-hidden from helpers/a11y.css). Number and check are CSS content with empty alt text and are not read - the list position ("3 of 4") comes from the list itself. An aria-label on the list names its purpose.

Preferences

The three states differ in shape (check / thick ring / thin ring, solid / dashed line). Forced colours: system colours, the current ring uses Highlight. No motion.

Without JS

Pure CSS; the state comes from the markup (server or your own script sets class/attribute).
