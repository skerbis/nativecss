Text & Image, Tiles

Two building blocks for typical marketing/landing-page sections: .ncss-split (text next to an image) and .ncss-tile (full-width color blocks, known from UIkit). Both are independent and combinable - a Tile as the background surface, a Split layout inside it.

1. Split: base structure

.ncss-split-container establishes the container-query context (an element can't query its own width by spec, see Cards, section 6 for the same constraint), .ncss-split is the actual two-column layout. From 36rem CONTAINER width the media and content columns sit side by side; below that they stack automatically.

<div class="ncss-split-container">
  <div class="ncss-split">
    <div class="ncss-split-media"><img src="photo.jpg" alt="..."></div>
    <div class="ncss-split-content">
      <h3>Title</h3>
      <p>Text ...</p>
    </div>
  </div>
</div>

Base example

Shrink the window/panel to see it stack below 36rem.

2. Image left vs. right

No modifier needed - plain document order, exactly like Cards (.ncss-card-media top/bottom). .ncss-split-media as the FIRST child = left (and on top when stacked), as the LAST child = right (and at the bottom when stacked). No row-reverse trick that would decouple reading/focus order from the visual layout.

<!-- Image right: .ncss-split-media simply as the LAST child -->
<div class="ncss-split">
  <div class="ncss-split-content">...</div>
  <div class="ncss-split-media">...</div>
</div>

Image right

Same class, just the child order in the markup is swapped.

3. Vertical alignment & width ratio

--ncss-split-align (default center) controls how the two columns align to each other once they sit side by side - no effect while stacked. Convenience classes for the most common values:

ClassEffect
.ncss-split--align-startBoth columns aligned to the top
.ncss-split--align-endBoth columns aligned to the bottom
.ncss-split--align-stretchBoth columns stretched to equal height

For an asymmetric width ratio (instead of 50/50), set --ncss-split-media-width directly on .ncss-split-media - the content column automatically fills the rest, always adding up to 100%:

<div class="ncss-split ncss-split--align-start">
  <div class="ncss-split-media" style="--ncss-split-media-width: 40%;">...</div>
  <div class="ncss-split-content">...</div>
</div>

40/60 split, top-aligned

Media narrower than the content column, both flush to the top instead of centered.

4. Tile: color-block sections

Known from UIkit (uk-tile-default/-muted/-primary/-secondary) - full-width blocks for dividing a long page into clearly distinct sections. .ncss-tile alone (no modifier) is the normal page surface, no visible difference from its surroundings besides its own padding.

ClassUIkit equivalentEffect
.ncss-tileuk-tile-defaultNormal page surface
.ncss-tile--muteduk-tile-muted--ncss-color-bg-subtle as background
.ncss-tile--branduk-tile-primaryBrand color, text automatically flips light
.ncss-tile--brand-2uk-tile-secondarySecondary color, text automatically flips light
 
<section class="ncss-tile ncss-tile--brand">
  <h2>Title</h2>
  <p>Text ...</p>
</section>

Brand surface

Light text automatically, no extra class needed.

5. White surfaces inside a Tile

The automatic light text of --brand/--brand-2 is a plain descendant-selector inheritance - without a countermeasure it would also leak into a nested white .ncss-card and become unreadable there (the same gotcha first found on product.html, solved generically here from the start). .ncss-tile therefore resets .ncss-card and <pre> INSIDE it back to normal dark text automatically:

6. Combined: Split inside a Tile

Both building blocks are deliberately independent - a Tile as the background surface, a normal Split layout inside it. For full screen width (instead of just the current container) additionally combine .ncss-full-bleed on the Tile - Tile itself doesn't break out of a surrounding .ncss-container on its own, that stays a deliberately separate decision.

<section class="ncss-tile ncss-tile--muted ncss-full-bleed">
  <div class="ncss-container">
    <div class="ncss-split-container">
      <div class="ncss-split">
        <div class="ncss-split-media">...</div>
        <div class="ncss-split-content">...</div>
      </div>
    </div>
  </div>
</section>
