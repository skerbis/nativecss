VS Code

Completion and hover help for <ncss-…> elements, data-ncss- attributes and every --ncss- token with its value, plus markup snippets (type the ncss- prefix) and class names via the "HTML CSS Support" extension. Setup: copy a ready block into .vscode/settings.json.

Package for LLMs and coding agents

So AI assistants don't invent classes: llms/GUIDE.md as a project guide (e.g. as CLAUDE.md/AGENTS.md), complete lists of all classes (llms/classes.json), elements, attributes and events (llms/components.json) and every file's header documentation (llms/reference.md). llms.txt in the root points to them.

The markup check node llms/hooks/check-classes.mjs <files> reports unknown ncss- classes (with suggestions), unknown attributes/elements, UIkit leftovers, modals without <dialog> and missing alt texts, names and labels - also as a Claude Code hook after every edit.
