Accessibility

helpers/a11y.css plus principles that run through the whole system rather than sitting in a single file.

Classes

ClassPurpose

.ncss-skip-link"Skip to content" link, visible only on focus - on every page directly after <body>

System-wide Principles

  • Native elements first - <dialog>, <details>, <fieldset>, <progress>/<meter> bring keyboard control, focus management and roles for free, with no ARIA reimplementation.
  • :focus-visible always stays ungated - unlike :hover, which is only active on real pointing devices (see Touch & Mobile Viewports).
  • prefers-reduced-motion is respected globally (the * selector includes html) - no animation has to check it individually.
  • Color contrast is part of the token palette: -on-soft text colors per family are checked against their own -100 surface, not guessed (see Colors & Surfaces).
  • .ncss-table-stacked is the one deliberate exception - breaks programmatic table semantics in favor of readability on narrow screens, see Known Limitations.
