Scroll Effects

Effects tied to the scroll position - native via animation-timeline: view() and (Chromium) scroll-triggered animations. JavaScript only as a small opt-in fallback or where CSS cannot reach (keyboard focus, state, events). Live demo.

Every effect is its own file and can be cherry-picked: it only needs colors.css/tokens.css/reset.css/base.css plus its own script where noted. Without support, with prefers-reduced-motion and in print everything stays plainly readable - no broken state.

Reveal shapes

helpers/reveal.css + optional js/reveal.js. Base class .ncss-reveal plus exactly one shape - on any element (image, <video>, section, card). Default: scroll-scrubbed (scrolling back rewinds). .ncss-reveal--once: plays once, time-based, when it scrolls in. No clip-path is left afterwards - focus rings and shadows are not cut off.

ModifierEffect
--circleiris from --ncss-reveal-x/-y (default centre)
--wipe-right / -left / -up / -downedge moves in the named direction
--inset / --split / --diagonalbox from the centre / curtain to both sides / diagonal edge
--zoomwindow opens while the media inside scales 1.15 → 1 - put it on a wrapper
--expandinset, rounded box grows to full size (full-bleed on a full-width element)
--fade / --slide-up / --scaleclassic entrances with the same mechanics (including --once)
 
<img class="ncss-reveal ncss-reveal--circle" src="..." alt="...">
<figure class="ncss-reveal ncss-reveal--zoom"><img src="..." alt="..."></figure>
<section class="ncss-reveal ncss-reveal--split ncss-reveal--once" data-ncss-reveal>...</section>
<script src="ncss/js/reveal.js" defer></script>

Parameters: --ncss-reveal-start/-end (default entry 25% / cover 45% - finishes just before the viewport centre), --ncss-reveal-inset, --ncss-reveal-radius, --ncss-reveal-scale, --ncss-reveal-duration (--once, 0.9s). Event ncss-reveal when the JS path starts.

Relation to .ncss-animate-on-scroll (Animations): that remains the lightweight shorthand (fade/slide only, scrub only). .ncss-reveal is the larger, self-contained variant with shapes, once mode and fallback - own keyframes, no dependency between the two files.

Reveal pin (media grows to full screen)

components/reveal-pin.css, no JS. Pinned stage: an image/video grows from a card to the full viewport, the intro fades out, a panel fades in. Fallback: everything stacked, media at 16:9. For <video autoplay> under reduced motion also add js/hero-video-motion.js.

<section class="ncss-reveal-pin" aria-label="...">
  <div class="ncss-reveal-pin-stage">
    <p class="ncss-reveal-pin-intro">Heading</p>
    <video src="clip.mp4" muted playsinline loop autoplay poster="frame.jpg"></video>
    <div class="ncss-reveal-pin-content">...</div>
  </div>
</section>

Parameters: --ncss-reveal-pin-length (250vh), --ncss-reveal-pin-inset (32% 14% 6%), --ncss-reveal-pin-radius.

Text reveal

components/text-reveal.css - text starts faint and brightens as it scrolls through. Lines (default) and flow (--flow, one inline child) without JS; word by word with js/text-reveal.js (the text stays identical for screen readers).

<p class="ncss-text-reveal">...</p>
<p class="ncss-text-reveal ncss-text-reveal--flow"><span>...</span></p>
<p class="ncss-text-reveal" data-ncss-text-reveal>...</p>

Parameters: --ncss-text-reveal-color, --ncss-text-reveal-from, --ncss-text-reveal-start/-end (default cover 15% / cover 50%).

Count-up

components/count-up.css + optional js/count-up.js. The real, formatted number is in the DOM (screen readers, copying, no JS); the counting happens in an ::after that is silent for assistive tech and fades back to the real text at the end. Thousands separators are missing while counting (counter() has none).

<span class="ncss-count-up" data-ncss-count-up style="--ncss-count-to: 12500">12,500</span>
<span class="ncss-count-up" data-ncss-count-up style="--ncss-count-to: 98; --ncss-count-suffix: '%'">98%</span>

Parameters: --ncss-count-to (required integer - if missing, the script reads it from the text), --ncss-count-from, --ncss-count-prefix/-suffix, --ncss-count-duration (2s).

Marquee

components/marquee.css + optional js/marquee.js. Endless ticker from two identical groups (the copy is aria-hidden + inert - the script creates it when only one group is in the markup). Pauses on hover (real pointing devices only) and focus. For meaningful content add a pause button (WCAG 2.2.2) - the script wires it up. Reduced motion: a static, swipeable row.

<div id="logos" class="ncss-marquee ncss-marquee--fade" data-ncss-marquee>
  <ul class="ncss-marquee-group" role="list"><li>...</li></ul>
</div>
<button type="button" data-ncss-marquee-toggle aria-controls="logos">Pause ticker</button>

Modifiers: --reverse, --slow, --fast, --fade, --paused. Parameters: --ncss-marquee-duration (30s), --ncss-marquee-gap.

Horizontal scroll

components/scroll-horizontal.css + recommended js/scroll-horizontal.js. Vertical scrolling moves a row sideways through a sticky stage. The script sizes the section to the row (1px down = 1px sideways, speed via attribute value) and brings tab-focused items into view (WCAG 2.4.11) - required for rows with links/buttons. Fallback: swipeable snap row.

<section class="ncss-scroll-horizontal" data-ncss-scroll-horizontal aria-label="Projects">
  <div class="ncss-scroll-horizontal-viewport">
    <div class="ncss-scroll-horizontal-track">
      <article>...</article> <article>...</article>
    </div>
  </div>
</section>

Parameters: --ncss-scroll-horizontal-length (300vh, overridden by the script), --ncss-scroll-horizontal-item, --ncss-scroll-horizontal-gap, --ncss-scroll-horizontal-padding.

Scrollytelling: <ncss-scrolly>

components/scrolly.css + js/scrolly.js (light-DOM custom element). The step crossing the trigger line becomes active (.is-active) and shows the media item with the same index; the media column sticks. Narrow: media on top, steps scroll underneath. Without JS: everything stacked.

<ncss-scrolly line="50" style="--ncss-scrolly-top: var(--ncss-topbar-height)">
  <div class="ncss-scrolly-steps">
    <div class="ncss-scrolly-step" data-ncss-time="0"><div>...</div></div>
    <div class="ncss-scrolly-step" data-ncss-time="4.5"><div>...</div></div>
  </div>
  <div class="ncss-scrolly-media">
    <figure class="ncss-scrolly-figure">...</figure>
    <figure class="ncss-scrolly-figure">...</figure>
  </div>
</ncss-scrolly>
APIMeaning
line (attribute)trigger line in % from the top (default 50)
media-start (attribute)media column on the left instead of the right
el.stepindex of the active step; assigning scrolls that step to the centre
data-ncss-time (step)time mark in seconds - hook for a scroll-driven video
Event ncss-scrolly-stepbubbles, detail = { index, time, step, figure } (time = number or null)
 
document.querySelector("ncss-scrolly").addEventListener("ncss-scrolly-step", (e) => {
  if (e.detail.time !== null) video.currentTime = e.detail.time;
});

Curtain sections

components/curtain.css, no JS. Each section holds still while the next one slides over it; --scale makes the covered one recede, --dim darkens it. No position: sticky - tall sections scroll through completely first. Every section needs an opaque background (e.g. .ncss-surface--* on the section itself). Combines with .ncss-snap-sections (snapping + curtain, see Scroll & Visibility).

<div class="ncss-curtain ncss-curtain--scale ncss-curtain--dim">
  <section class="ncss-surface--brand">...</section>
  <section class="ncss-surface--neutral">...</section>
</div>

<div class="ncss-snap-sections ncss-curtain ncss-curtain--dim">
  <section class="ncss-snap-section ncss-surface--brand">...</section>
  ...
</div>

Parameters: --ncss-curtain-height (100svh), --ncss-curtain-scale (0.88), --ncss-curtain-dim (0.45), --ncss-curtain-radius. For a pinned stage with cards instead of real sections: components/scroll-stack.css (Stacked Cards).
