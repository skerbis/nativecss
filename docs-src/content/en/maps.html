Maps

<ncss-map> shows an interactive vector map with MapLibre GL (self-hosted in vendor/maplibre/, BSD-3-Clause). The main goal is privacy: with the proxy attribute every request of the map goes through your own server - visitors never connect to a map provider directly. Files: components/map.css + js/map.js, usable on their own (only colors.css/tokens.css/reset.css/base.css required).

Live example

This documentation is a static site (GitHub Pages) without a server proxy. The map below therefore loads directly from OpenFreeMap (tiles.openfreemap.org) - but only after you click “Show map” (two-click mode). Nothing is loaded from third parties before that. On your own website set proxy instead, then the click is no longer needed.

Controls: Tab to the map, ← ↑ → ↓ pan, +/− zoom, with view3d Shift + arrows rotate and tilt. The mouse wheel only zooms with Ctrl/⌘, on touch two fingers pan (cooperativeGestures) - so page scrolling is never hijacked.

Privacy: a proxy instead of third parties

A web map loads a style (JSON), tiles, fonts (glyphs) and icons (sprites) - normally straight from the map provider, and every request transmits the visitor's IP address. With proxy, <ncss-map> rewrites each of these requests through MapLibre's transformRequest to your server, which fetches (and can cache) the data. Result: no contact with third parties, no consent required, no cookies.

FormExamplehttps://tiles.openfreemap.org/planet/…/1/0/0.pbf becomes
Prefix (origin is replaced)proxy="/proxy/ofm/"/proxy/ofm/planet/…/1/0/0.pbf
Template with {url} (URL-encoded)proxy="/proxy?url={url}"/proxy?url=https%3A%2F%2Ftiles.openfreemap.org%2Fplanet%2F…
Template with {host}/{path}proxy="/proxy/{host}/{path}"/proxy/tiles.openfreemap.org/planet/…/1/0/0.pbf

By default every foreign origin is rewritten (everything except your own page and the proxy itself); proxy-origins="tiles.openfreemap.org" limits this to specific servers. The prefix form fits when all data comes from one server (OpenFreeMap: style, TileJSON, tiles, glyphs and sprites all live on tiles.openfreemap.org). If your style references several servers, use the {url} template.

nginx

# /proxy/ofm/… -> https://tiles.openfreemap.org/… (cached)
proxy_cache_path /var/cache/nginx/ofm levels=1:2 keys_zone=ofm:10m max_size=2g inactive=30d;

server {
  # …
  location /proxy/ofm/ {
    proxy_pass https://tiles.openfreemap.org/;
    proxy_ssl_server_name on;
    proxy_set_header Host tiles.openfreemap.org;
    proxy_set_header Cookie "";
    proxy_set_header X-Forwarded-For "";      # do NOT pass on the visitor's IP
    proxy_hide_header Set-Cookie;
    proxy_cache ofm;
    proxy_cache_valid 200 1d;
    add_header X-Cache $upstream_cache_status;
  }
}

PHP (one file, with an allowlist)

<?php
// proxy.php - call: /proxy.php?url={url}  →  <ncss-map proxy="/proxy.php?url={url}">
// Sketch: add caching, a size limit and rate limiting before production use.
$allow = ['tiles.openfreemap.org'];               // ONLY these hosts - otherwise an open relay
$url   = (string) ($_GET['url'] ?? '');
$parts = parse_url($url);
if (($parts['scheme'] ?? '') !== 'https' || !in_array($parts['host'] ?? '', $allow, true)) {
    http_response_code(403);
    exit;
}
$ch = curl_init($url);
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_FOLLOWLOCATION => false,
    CURLOPT_TIMEOUT        => 15,
    CURLOPT_USERAGENT      => 'site-map-proxy',     // pass on no visitor data
]);
$body = curl_exec($ch);
$code = curl_getinfo($ch, CURLINFO_RESPONSE_CODE) ?: 502;
$type = curl_getinfo($ch, CURLINFO_CONTENT_TYPE) ?: 'application/octet-stream';
http_response_code($code);
header('Content-Type: ' . $type);
header('Cache-Control: public, max-age=86400');
echo $body;

The allowlist matters: a proxy that fetches arbitrary URLs is an open relay. A proxy that serves style JSON with already rewritten addresses is fine too - addresses on your own page or the proxy are not rewritten a second time.

Built in: the REDAXO add-on fluid already ships a map proxy for OpenFreeMap (/proxy/ofm/…, with caching and an area limit) - there proxy="/proxy/ofm/" is all you need.

Fallback content and two-click mode

Whatever you put inside <ncss-map> - an address, directions, a link to OpenStreetMap - is the fallback content. It is visible without JavaScript, while the map has not loaded yet and if loading fails (then with the note “The map could not be loaded.”). The element is never empty. Only once the map has finished drawing does it cover the fallback; the fallback stays in the accessibility tree and reappears at the bottom of the map when a link inside it receives keyboard focus. With fallback="below" it stays visible below the map.

Lazy loading: MapLibre (about 1.1 MB) loads only when the map scrolls near the viewport. Until then a calm grid reserves the space, nothing jumps.

Two-click mode (consent): instead of loading automatically, the map shows a short privacy note and a “Show map” button. Without proxy the note names the map server and says that the IP address is transmitted; with proxy it says that your server fetches the data. privacy-url adds a link to your privacy policy. When the device reports Save-Data the mode turns on automatically - nobody downloads a megabyte of map unasked.

Accessibility, dark mode, motion

  • The map is a named region (“Map: Lake Tollense”); the map surface itself is focusable and announces its keys, the marker has an aria-label. Focus is clearly visible on the map, buttons and links.
  • A map is barely usable with a screen reader - so the fallback content is the real text alternative: always put the address and a link in it.
  • Dark mode: when <html data-theme-resolved="dark"> (or data-theme="dark", or a dark system setting) applies, the map loads style-url-dark - live when switching, including via <ncss-preferences>.
  • Reduced motion (prefers-reduced-motion or <html data-motion="reduce">): no camera flights, no cross-fade, view3d starts tilted right away.
  • Forced colors: system colors for border, note and button, the marker stays visible.
