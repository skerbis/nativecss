<ncss-container> in einer fremden Seite

Diese komplette Seite läuft auf UIkit 3 - eigenes Reset, eigene Typografie, eigene Buttons/Cards. Mitten drin: ein <ncss-container> mit echtem NativeCSS-Inhalt (Stacked Cards), per Shadow DOM vollständig isoliert - kein CSS läuft in irgendeine Richtung über die Grenze.

<script src="dist/components/ncss-container.js" defer></script>

<ncss-container src="dist/ncss.css">
  <div class="ncss-card">
    <div class="ncss-card-body">Isolierter Inhalt</div>
  </div>
</ncss-container>
Alles hier oben ist reines UIkit: - Schriftart, Radius, Farben kommen ausschließlich aus uikit.min.css.

Isolierter ncss-container

Native CSS Design System

Dieser komplette Block läuft in einem eigenen Shadow Root mit eigener, unveränderter ncss.css - eigene Tokens, eigener Reset, eigene Cascade Layers. UIkits button/h1-h6-Reset erreicht diesen Bereich nicht; ncss' eigener Reset (* { margin: 0 } u.a.) bleibt umgekehrt auf diesen Bereich beschränkt und beeinflusst UIkit oben/unten nicht.
