# Demo-Medien – Herkunft

Alle Videos, Bildsequenzen, Poster, Musikstücke und Cover in diesem Ordner wurden für NativeCSS
**selbst erzeugt**: Szenen per `<canvas>` im Browser gerendert und mit ffmpeg kodiert, Musik
synthetisch erzeugt (Pads/Akkorde), Untertitel und Kapitel selbst geschrieben. Es sind keine
Fremd- oder Stock-Inhalte enthalten.
