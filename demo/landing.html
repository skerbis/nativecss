v1.0 · Reines CSS, kein Build-Schritt

Ein Design System, das nicht im Weg steht.

NativeCSS verbindet natives CSS (Cascade Layers, Container Queries, light-dark()) mit Web Awesome und Font Awesome - ohne LESS, ohne Compile-Schritt, ohne Utility-Klassen-Wildwuchs. Diese Seite ist selbst das Beispiel.

Preise ansehen Demo anfragen

Alles, was ein Design System heute braucht

Native Browser-Mechanismen zuerst - Web Awesome ergänzt gezielt dort, wo ein fertiges Komponenten-Verhalten schneller zum Ziel führt.

Zero Build

Kein LESS, kein Sass, kein Bundler. @import und Cascade Layers regeln die Reihenfolge.

CSS only @layer

Fließend & responsiv

Fließende clamp()-Skalen als Standard, Container Queries statt Viewport-Breakpoints Reagiert auf die Breite des umgebenden Containers, nicht die des Viewports - dieselbe Karte bleibt in einer schmalen Sidebar automatisch gestapelt. .

clamp() @container

Barrierefrei per Default

Native <dialog>/<details>, Fokus-Trap, :focus-visible - Tastatur und Screenreader ab Werk statt nachgerüstet.

a11y native HTML

Ein Token-System, zwei Bibliotheken

Web Awesome übernimmt ncss-Farben/-Radien/-Schriften über eine einzige Bridge-Datei - keine zweite, konkurrierende Werteliste.

Design Tokens Web Awesome

Im Detail

Container Queries statt Viewport-Breakpoints

Dieselbe Karte verhält sich in einer schmalen Sidebar anders als im breiten Hauptbereich - automatisch, ohne JavaScript, ohne dass die Seite weiß, wo die Komponente gerade eingebettet ist. Klassische Viewport-Breakpoints kennen nur die Fensterbreite, nicht den tatsächlich verfügbaren Platz.

Was ist enthalten

Kompletter Aufbau als <wa-tree> - klappt per Klick/Tastatur auf, ohne eigenes JS.

Layout & Helpers Container, Grid, Stack, Cluster Typografie (Drop Cap, Silbentrennung, tabellarische Ziffern) Textumfluss (float + shape-outside) Sichtbarkeit & Breakpoint-Escape-Hatch Komponenten Card, Placeholder, Badge, Sparkline Modal, Off-Canvas, Nav (native <dialog>) Slideshow, Disclosure, Select Web-Awesome-Bridge Farb-Tokens (fill/border/on × quiet/normal/loud) Typografie- & Radius-Tokens Font Awesome Icons (selbst gehostet)
