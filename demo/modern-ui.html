Moderne UI

Bento-Raster, Spotlight, Vorher/Nachher-Vergleich, Aufklapp-Panels, Befehlspalette, Hovercards, Benachrichtigungen und Aurora-Hintergründe - jede Komponente eine eigene CSS-Datei (plus höchstens ein Script), einzeln einbindbar.

Bento-Raster

Erweitert das vorhandene .ncss-bento (helpers/layout.css): eigener Container - zu schmal für eine Spannweite, fällt sie weg, statt seitlich überzulaufen. Neu: Vorlagen .ncss-bento--hero / --mosaic (Spannweiten nach Position, keine Klassen an den Kacheln) und mitwachsende Zeilen. Kombiniert hier mit .ncss-spotlight als Gruppe. Spotlight

Ein Lichtkegel folgt dem Mauszeiger, dazu leuchtet das Rand-Segment nahe am Zeiger auf. data-ncss-spotlight an der Gruppe: ein Listener für alle, Nachbarn fangen den Rand des Lichts auf. Ohne JS und bei Tastatur-Fokus steht das Licht in der Mitte. components/spotlight.css + js/spotlight.js.

Standard

Ganze Karte klickbar (.ncss-card--linked) - Tab auf den Link zeigt das Licht ebenfalls.

Kräftig

.ncss-spotlight--strong

Eigene Farbe

--ncss-spotlight-color / -border

<div class="ncss-grid" data-ncss-spotlight>
  <article class="ncss-card ncss-spotlight">...</article>
  <article class="ncss-card ncss-spotlight ncss-spotlight--strong">...</article>
</div>

Vorher/Nachher-Vergleich

Befehlspalette

<ncss-command-palette shortcut="k"> um einen <dialog>: öffnet ohne JS über command="show-modal", mit JS zusätzlich per ⌘K / Strg+K. Combobox + Listbox nach APG: Fokus bleibt im Feld, ↑/↓ wählt, Enter führt aus, Esc schließt. Filter ignoriert Groß-/Kleinschreibung und Akzente, data-keywords liefern Zusatzbegriffe.

Benachrichtigungen

ncss.notify() oder data-ncss-notify am Button. Die Timer pausieren, solange Zeiger oder Fokus in der Region sind. Fehler (danger) bleiben stehen, bis sie geschlossen werden. Die Region liegt im Top Layer - Meldungen erscheinen auch über einem offenen Modal.

Gestapelt (Sonner-Stil)

Mehrmals klicken: ältere Meldungen stapeln sich hinter der neuesten, bei Hover oder Tastatur-Fokus fächern sie sich auf.

ncss.notify("Gespeichert", { status: "success" });
ncss.notify({ title: "Upload fehlgeschlagen", message: "Datei zu groß",
              status: "danger", position: "top-start" });
ncss.notify("Kopiert", { position: "bottom-end", stack: true, timeout: 8000 });
<button type="button" data-ncss-notify="Gespeichert" data-status="success">Speichern</button>
<script src="ncss/js/notification.js" defer></script>

<!-- serverseitig gerenderte Meldung (bleibt ohne JS einfach stehen) -->
<ncss-toast-region position="top-end">
  <div class="ncss-notification ncss-notification--success" data-timeout="6000">
    <p class="ncss-notification-title">Gespeichert</p>
  </div>
</ncss-toast-region>

Aurora & Mesh

Weiche, treibende Farbfelder aus den Markenfarben - nur transform, kein Blur-Filter. Bei reduzierter Bewegung statisch, in Forced Colors aus.

Aurora

.ncss-aurora - zwei gegenläufig treibende Ebenen.

Aurora kräftig

.ncss-aurora--vivid - für kurze Texte und große Überschriften.

Mesh

.ncss-mesh - vier Felder, langsam drehend.

<section class="ncss-aurora">...</section>
<section class="ncss-aurora ncss-aurora--vivid">...</section>
<section class="ncss-mesh">...</section>
